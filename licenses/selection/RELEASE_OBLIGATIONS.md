# 선정 구성의 배포 의무 추적

2026-09-05 · 상태: 선정 단계 검토 완료, 실제 설치 파일 검토 전

이 문서는 사용자에게 배포할 최종 고지문이 아니다. 각 구성의 최종 포함 여부와 변경 사항을 확인하여 제품의 Third-party notices를 만들어야 한다.

| 구성 | 지금 확보한 근거 | 배포 전에 수행할 일 |
|---|---|---|
| RF-DETR Small | 공식 Apache 원문, 가중치 출처·해시 | 고지·해당 NOTICE 보존, 수정 사항 표시, 학습 결과와 초기 가중치 연결 |
| 일반 DINOv2 Small | 정확한 모델 커밋·해시, Meta Apache 원문·모델 범위 설명 | 일반 모델 범위를 유지하고 별도 비상업용 변종 혼입 방지 |
| PatchCore 참고 코드 | 고정 소스 커밋·Apache 원문 | 재사용·수정 파일에 기존 고지 및 변경 표시 |
| Qwen3.5-4B | 공식 커밋·모델 LICENSE·모든 가중치 해시 | 모델 라이선스와 저작권 보존; 양자화·변환 시 출처와 변경 기록 |

제품 전체의 라이선스를 Apache/GPL/LGPL로 지정하지 않는다. 의존성의 라이선스 선택과 제품 자체의 이용 조건은 구분한다. 실제 LGPL 라이브러리에 대한 사용자 권리를 제품 이용 조건으로 제한하지 않는다.
