# 전체·상세 촬영 검사 운영

2026-09-09. `scripts/desktop.py`의 기본 화면을 로봇 장착 카메라 방식으로 전환했다. 현재 연결 범위는 **전체 촬영부터 개별 상세 검사 및 선택적 OK·NG 분류 이송까지**다. `검사 후 자동 분류`를 켜면 모든 상세 검사 뒤 이송하며, 기본 선택은 OFF다. 자세한 내용은 [분류 이송 안내](STATION_SORTING.md)를 참고한다. 실제 장비 연결·이동, 실물 학습, 모델 정확도·처리 시간 측정은 수행하지 않았다.

## 운영 화면과 검사 흐름

검사 시작은 저장된 회차 요청에 따라 전체 촬영 위치 이동 → 정지·안정화 → 새 전체사진 저장 → 위치 검출·좌표 변환 → 물체별 근접 이동·촬영·판정을 수행한다. 전체사진으로 OK/NG를 판정하지 않는다. 겹침, 영역 이탈, 상세 물체 식별 또는 화질이 불확실하면 보류로 표시한다. 자동 분류가 꺼져 있으면 마지막 상세 검사 후 완료한다. 켜져 있으면 OK·NG만 등록 목적지로 이송하고 보류는 남긴다.

- 왼쪽은 해당 회차의 저장된 전체사진과 물체 목록이다. 물체 또는 목록 행을 선택하면 오른쪽 상세사진과 판정이 함께 바뀐다. 전체사진과 상세사진의 표시 좌표는 각각의 원본 기준이다.
- 오른쪽 아래에는 기본 판정·불량 종류·이유와 VLM 설명을 나눠 표시한다. 기본 판정은 VLM OFF 또는 설명 대기 중에도 확인할 수 있다.
- `카메라 영상`은 별도 미리보기 창이다. 새 미리보기 프레임으로 저장된 전체사진을 덮어쓰지 않는다.
- `검사 중단`은 다음 단계 실행 권한을 먼저 해제하고 로봇 정지를 요청한다. 진행 중 추론·저장 완료를 기다린 뒤 정지를 요청하는 방식이 아니다. 카메라 연결과 이미 저장된 결과는 유지한다. 늦게 도착한 응답은 새 판정이나 이동에 사용하지 않는다.
- 중단·재연결·장면 변경 후에는 장치와 오류 상태를 확인하고 새 전체 촬영 회차로 시작한다. 중단된 작업을 재실행하거나 예전 좌표로 자동 재개하지 않는다.
- 한국어·영어·중국어·태국어를 즉시 전환한다. 작은 화면은 필요한 경우 스크롤하며 전체/상세 영상과 설명 영역을 함께 배치한다.

## 준비 순서

장비 연결 전에 실행할 통합 점검 명령과 실제 설치 후의 검증 순서는 [사전 점검·현장 검증 안내](STATION_COMMISSIONING.md)에 정리했다. 등록 자료 확인과 소프트웨어 시험이 통과해도 실물 검증 완료를 의미하지 않는다.

1. 품목에 상세 촬영용 물체·불량 모델과 정상 기준, 검사 정책 등 필요한 검증 자료를 등록한다. 과거 고정 카메라 자료를 새 상세 촬영용 자료로 자동 인정하지 않는다.
2. `장비 · 보정`에서 실제 촬영 조건, 촬영·집기 보정 묶음과 이동 자세, 영상 최대 지연 검증 기록을 등록한다. 수치가 미등록이면 실제 검사 시작 조건을 충족하지 못한다. 측정·검증 방법은 [촬영·보정 설정](ROBOT_CAMERA_SETUP.md)을 참고한다.
3. 등록된 보정 묶음을 사용하는 로봇 운전 프로필을 작성한다. 검증된 작업 범위·목적지·입력 신호 등을 실제 설치 자료로 채워야 한다. 저장만으로 로봇을 움직이지 않으며, 자동 분류 선택과 검사 시작이 필요하다.
4. `품목 설정 → 전체·상세 검사 설정`에서 전체 위치 검출용 모델 파일을 지정한다. 상세 촬영용 자료와 전체 상세영상 검사 영역을 검증했음을 기록한다. 현재 상세 검사 영역은 전체 이미지이며 사용자 지정 상세 ROI는 아직 지원하지 않는다.
5. 모델 준비 후 카메라와 로봇을 명시적으로 연결하고 준비 확인을 수행한다. 현재 프레임·장치 세션·로봇 연결 상태·설정 및 파일 식별값이 일치해야 검사 시작이 가능하다.

전체·상세 설정은 품목 버전, 장비 버전, 영상 크기, 모델 파일 식별값에 묶인다. 품목이나 장비를 수정하면 해당 설정을 다시 확인해야 한다. 이 확인은 실제 품질 평가를 대신하지 않는다. 현재 모델 공급자는 기존 RF-DETR/DINO를 유지했으며 새 모델을 다운로드하거나 학습하지 않았다.

## 저장·VLM·이력

촬영·추론·원본 저장은 별도 프로세스에서 한 요청씩 처리한다. 저장이 지연되어도 UI와 로봇 정지 요청은 독립적이다. 중단 후 프로세스가 종료되지 않으면 제한 시간 뒤 종료를 시도하며 살아 있는 동안 새 작업을 허용하지 않는다. 비정상 종료 때 남은 미완성 파일은 결과로 채택하지 않고 자동 삭제하지 않는다.

상세 원본과 기본 결과를 검증하여 저장한 뒤 기존 VLM 큐에 연결한다. ON 상태의 자동 대상은 품목의 VLM 정책을 따른다. 모든 보류를 무조건 보내지 않으며, 물체 연결이 확정되지 않은 사진에는 유효한 단일 물체 검사 자료가 없을 수 있다. 설명 수신 시 물체 ID와 기본 결과 식별값을 다시 확인한다. 설명은 보조 정보이고 기본 판정이나 로봇 명령 권한을 바꾸지 않는다.

VLM의 GPU 사용은 기존 조정 정책을 따른다. 메모리 여유가 충분하면 별도 작업자가 설명을 생성하고, 부족하면 기본 검사 모델을 해제한 후 실행을 기다릴 수 있다. 검사 흐름은 VLM 완료를 기다리지 않는다. ON이라고 모든 장비에서 검사와 VLM이 동시에 GPU 추론한다는 의미는 아니다.

`검사 이력`에서 기존 기록과 새 회차 물체 결과를 함께 검색·검토·내보낼 수 있다. 최근 100개 회차 보조 목록은 펼쳐서 확인한다. 보존 기간이 지난 새 회차는 전체·상세 원본을 묶어 검증 후 보관 이동한다. 사용법과 보호 조건은 [STATION_HISTORY.md](STATION_HISTORY.md)를 참고한다.

백업은 새 회차 DB·촬영 원본·상세 근거·VLM 연결과 외부 전체 모델·보정 파일을 포함한다. 복원 시 과거 결과는 유지하되 미완료 회차를 중단 상태로 바꾸고 좌표·미결 요청·설치 설정의 운전 권한을 해제한다. 복원한 자료만으로 로봇이 자동 재개하지 않는다. 다시 측정 자료와 촬영 조건을 확인하여 등록해야 한다.

## 검증과 남은 작업

자동 검사는 주입한 영상·검출 결과·모의 로봇으로 검사 시작부터 상세 결과까지의 연결, 여러 물체의 개별 사진 연결, VLM OFF의 NG 이유, 늦은 응답 무시, 저장 실패 시 정지 우선, 원본 변조 거부, 복원 후 운전 권한 해제, 네 언어 전환을 확인한다. 별도 프로세스 시험도 주입한 모델을 사용하며 실제 AI 성능 측정이 아니다. 화면 확인 자료의 회색 영상은 검사용 입력이다.

이전 운영 UI 연결 단계의 전체 자동 검사 **605개 통과(104.098초)**. 최신 분류 변경의 검증은 [분류 이송 안내](STATION_SORTING.md)를 참고한다. 신규 운영 검사 15개가 포함된다. 네 언어 × 두 창 크기의 완료 화면 8장과 미등록 화면 1장을 렌더링했고 한국어·태국어 배치를 직접 확인했다. 최종 검사 로그와 화면 확인 자료는 `artifacts/station-ui/`에 보존한다.

**전체사진 집기 좌표와 상세 판정 근거를 동시에 검증하는 분류 계획·이송은 연결했다.** 새 회차 이력의 검색·내보내기·수동 검토·보존 정책도 통합했다. 사용법은 [STATION_HISTORY.md](STATION_HISTORY.md)에 정리했다. 이후 실제 장착 구조·전체 경로·좌표 오차·근접 화질·불량 통과/오탐/보류·처리 시간을 검증하고 노트북에서 확인한다. 설치 배포는 해당 검증 후 진행한다.
