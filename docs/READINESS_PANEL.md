# 검사 준비 상태 통합 · 4번

2026-09-07. 실시간 검사 페이지에 품목·검사 조건, 검사 모델, 카메라 영상, 좌표 보정, 검사 원본 저장, 로봇 자동 분류의 6개 상태 카드를 추가했다. 미해결 운전 오류는 기존 오류 확인 표시와 함께 시작 차단 사유에 반영한다.

## 화면과 시작 조건

- 패널 상단은 검사 시작 가능 여부와 첫 차단 사유, 나머지 확인 건수를 표시한다. 전체 차단 사유는 요약과 시작 버튼의 툴팁에서 볼 수 있다. 각 카드에는 상태와 해당 항목의 상세 사유 툴팁이 있다.
- 카드를 누르면 품목 설정, 모델 준비, D405 연결, 좌표 보정, 저장·백업 관리, 로봇 준비 확인이 있는 페이지로 이동하고 해당 컨트롤에 초점을 맞춘다. 바로가기만으로 장비 연결·모델 적재·로봇 명령·검사 시작을 수행하지 않는다.
- 큰 창에서는 3열 × 2행, 작은 창에서는 2열과 스크롤로 표시한다. ‘검사 준비 상태’ 버튼으로 패널을 접고 펼칠 수 있다. 네 가지 언어를 지원하며 긴 문구는 카드 안에서 줄바꿈한다.
- 카메라는 연결 표시 외에 0.5초 이내 새 영상이 있어야 준비 완료다. 모델은 실제 준비 완료 응답을 기준으로 한다. 준비 패널 표시와 검사 시작 함수가 같은 준비 조건을 사용한다.
- 검사만 수행할 때는 좌표 보정/로봇을 자동 분류 시 필수 항목으로 안내한다. 자동 분류를 켜거나 자동 분류 상태로 검사를 시작할 때는 보정과 로봇 운전 설정, 현재 로봇 준비 상태 및 새 상태 응답을 요구한다. 검사 중 자동 분류를 켜는 경우에도 같은 확인을 적용한다.
- 좌표 보정은 검증된 실물 보정인지, 품목·카메라 촬영/설치 조건·영상 크기/변환·검사면 높이가 일치하는지 확인한다. 로봇 운전 설정은 품목/보정/집기 기준과 검증 기록을 확인한다. 실제 움직임에 대한 기존 개별 물체 좌표·작업 계획·집기 가능 여부 검증은 그대로 유지한다.

## 조회와 저장 검사

파일/정책/저장소 확인은 단일 백그라운드 작업에서 기본 5초 간격으로 실행한다. 설정이 바뀌면 이전 결과를 무효화하고 다시 확인한다. 15초를 넘긴 확인 결과로 새 검사를 시작하지 않는다. 카메라 신선도와 로봇/오류 상태는 기존 40ms 감시 흐름에서 계산한다. 모델 가중치 전체 해시는 반복 검사하지 않으며 모델 준비 시 기존 검증을 사용한다.

저장 확인은 기존 최소 여유 공간 정책을 적용하고 검사 원본 폴더에 임시 파일을 쓰고 동기화한 뒤 제거한다. SQLite의 임시 확인 항목은 트랜잭션을 롤백하므로 운영 이력이나 설정에 남지 않는다. 저장 관리와 같은 사용권을 적용하고, 저장 관리 창은 진행 중인 확인이 끝난 뒤 열린다. 관리 창 종료 후 저장 상태를 다시 확인한다. 저장 확인 실패는 준비 미완료로 표시하며 오류를 숨기고 시작을 허용하지 않는다.

이 패널은 준비 안내와 새 검사 시작 조건이다. 검사 실행 중 저장 공간 변동, 카메라/로봇 연결 끊김 등의 기존 오류 감시와 저장 시 검사, 로봇 동작별 검증을 대체하지 않는다. 확인 시점 이후의 물리적 이동이나 디스크 상태까지 보장하지 않는다.

## 검증

관련 시험 91개를 먼저 통과했고 배치 및 저장 관리 동시 접근 보완 후 전체 **457개 시험을 통과했다(82.958초)**. 새 준비 상태 시험 13개는 시작 조건 일치, 검사 전용/자동 분류 구분, 저장 실패·결과 만료·이전 설정 응답 무시, 반복 조회 억제, 오류 우선 차단, 장비를 시작하지 않는 바로가기, 저장 확인 흔적 제거, 좌표 보정 조건 불일치, 저장 관리 대기와 결과 무효화를 확인한다.

한국어·영어·중국어·태국어 각각 기본 크기, 1080×720 창, 130% 글씨, 준비 완료 상태의 총 16개 화면을 렌더링했다. 카드 문구의 필요한 높이를 검사하고 한국어 기본 화면과 태국어 작은 창을 시각 확인했다. 시험 화면은 임시 자료와 명시적 검증 상태를 사용하며 운영 이력에 등록하지 않는다. 실제 카메라·Dobot·설치 환경·노트북 실운전 검증은 아직 하지 않았다.
