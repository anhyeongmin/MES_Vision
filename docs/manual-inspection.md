# 수동 도착 검사

실행: 프로젝트 루트의 `MES Vision Manual.cmd`.
기존 프로그램이 열려 있다면 품목 설정 → **수동 도착 검사**를 사용한다.
기존 프로그램에서 열 때는 모델과 로봇 연결을 해제하고, 카메라는 연결해 둔다.
단독 실행은 저장된 장비 설정의 U20CAM을 사용한다. 장비가 미등록이면 본 프로그램에서 먼저 등록한다.
두 실행 방식은 같은 desktop.lock을 공유한다. 수동 창은 로봇 명령을 보내지 않는다.

## 사용 순서

1. 필요하면 **모델 묶음 선택** 또는 **불량 모델 교체(.pth)**에서 학습이 끝난 모델을 고른다.
   기본 묶음은 기존 `ash-trained-v3.json`이다. 최신 학습 결과를 자동으로 선택하지 않는다.
   불량 모델 교체는 NG01~NG06 순서로 학습한 RF-DETR Small 체크포인트용이다.
   클래스 순서와 모델 해시는 검사 프로세스에서 확인하며 맞지 않으면 검사를 실패 처리한다.
2. **모델 미리 로드**로 전체·상세·불량 모델을 준비한다. 생략하면 첫 촬영 때 로드한다.
   카메라 연결 → 카메라를 전체 촬영 위치에 두고 **풀뷰 도착 · 촬영**.
3. 기본 1.5초 고정 대기 후 새 프레임을 저장한다. 자동으로 흔들림을 측정하는 기능은 아니므로 손을 고정한다.
4. 왼쪽 사진이나 표에서 물체 번호를 선택한다.
5. 카메라를 해당 물체 바로 위로 옮겨 중앙에 하나만 보이게 한 뒤 **물체 N번 도착 · 상세검사**.
6. 선택한 번호에 상세사진과 불량 후보 설명이 연결된다. 다른 번호를 누르면 해당 결과로 바뀐다.
7. **취소**는 촬영 대기/추론만 취소하고 영상은 유지한다. **새 회차**는 화면을 초기화하며 저장 파일은 남긴다.

## 왜곡보정과 기록

- `artifacts/camera-calibration/video-20260914/exploratory-calibration.json`의 U20CAM 1280×720 보정을 적용한다.
- 전체 원본을 보정한 다음 중앙 720×720으로 크롭한다. 중앙 1:1 크롭을 해제하면 보정된 1280×720을 쓴다.
- 실시간 화면, 저장사진, 검출, 클릭 좌표가 동일한 보정/크롭 공간을 사용한다.
- 실제 렌즈/초점이 캘리브레이션 때와 달라졌다면 다시 보정해야 한다. 현재 데이터는 임시 보정이며 로봇 정밀 좌표로 승인된 값이 아니다.
- `artifacts/operation/manual-inspections/<회차>/`에 원본, 전체 보정본, 검사 입력, 캡처 조건/해시, 모델 묶음, 추론 로그, 번호별 연결 기록을 저장한다.
- 번호 연결은 사용자가 올바른 물체 위로 옮겼다는 전제이다. 물리적으로 같은 물체인지 확인하거나 픽셀을 로봇 mm 좌표로 바꾸지 않는다.

## 현재 검사 범위

기존 저장사진 검사기를 사용한다. 상세사진에서 중앙 물체 하나를 검출했을 때 해당 물체의 불량 검사를 한다.
NG01~NG06 후보와 점수를 표시하되, 불량 미검출을 정상 확정으로 바꾸지 않는다. 미검증 판정 기준에서는 최종 보류를 유지한다.
VLM은 호출하지 않는다.

모델은 별도 프로세스에서 최초 한 번 로드하고 전체·상세 촬영 및 새 회차에 재사용한다.
**모델 해제** 또는 창 닫기로 GPU 메모리를 반환한다. 모델 변경 시 다음 로드/촬영에서 교체한다.
추론 중 취소·오류·시간 초과는 작업 프로세스를 종료하므로 다음 검사에서 다시 로드한다. 촬영 대기만 취소하면 로드된 모델은 유지한다.
모델 유지 중에는 같은 runtime의 VLM GPU 작업도 기다린다. 사용 후 모델을 해제한다.
표시되는 검사 처리 시간은 사진 읽기·추론·저장을 포함하고 최초 모델 로드 시간은 제외한다. 실제 GPU 처리 시간은 실측해야 한다.
모델 작업 로그는 `artifacts/operation/manual-model-workers/<작업>/`에 저장된다.
학습 작업과 모델 산출물은 수정하지 않는다. GPU가 학습에 사용 중이면 검사를 동시에 시작하지 않는 편이 좋다.
