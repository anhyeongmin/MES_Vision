# 장비 목록 선택 · 개선 5번

> 2026-09-11 업데이트: **INNOMAKER U20CAM-720P용 UVC 입력과 설정·촬영·저장·검사 연결을 구현했다.** 현재 사용법과 장비 준비 후 확인 사항은 [U20CAM 입력 안내](U20CAM_INPUT.md)를 참조한다. 아래는 D405 구현 당시의 기록이다. 실제 U20CAM 수신·노출·지연·렌즈/좌표 보정은 실장비에서 확인해야 한다.

2026-09-07. 장비 검색 결과를 설정창의 D405 시리얼 및 Dobot 통신 포트 선택 목록에 연결했다. 카메라의 해상도·FPS는 선택한 D405에서 조회한 컬러 영상 지원 모드를 우선 사용한다.

## 사용 방법

1. 프로그램을 다시 실행하고 **장비·보정 → 장치 검색** 또는 **장비 설정**을 연다. 설정창이 열리면 자동으로 검색한다. 기존 설정 변경 조건에 따라 모델을 해제하고 카메라·로봇 연결을 해제한 상태에서 진행한다.
2. 카메라 탭에서 D405 이름과 시리얼을 선택하고 영상 해상도·초당 프레임을 고른다. Dobot 탭에서는 포트 이름과 설명을 보고 해당 로봇의 포트를 선택한다. 일반 시리얼 포트도 표시되며, 포트 검색만으로 Dobot임을 확정하지 않는다.
3. USB 연결을 바꿨다면 **장치 다시 검색**을 누른다. 검색/선택만으로 설정을 저장하거나 영상 수신·로봇 연결·동작을 시작하지 않는다.
4. 촬영 조건을 변경했다면 촬영 조건 버전을 변경하고 좌표 보정을 재확인한다. 저장 후 기존 D405 연결 버튼으로 영상 수신을 시작한다.

## 선택값과 지원 모드

- 장치가 하나만 발견돼도 임의로 선택하지 않는다. 새 검색에서도 저장값과 현재 수정 중인 선택값을 유지한다. 실제 저장은 시리얼/포트 식별자를 사용하며, 화면의 제품명·설명·상태 문구는 저장하지 않는다.
- 장비가 없거나 검색에 실패하면 선택값을 ‘검색에서 확인되지 않음’으로 남긴다. 직접 식별자를 입력해 장비 없이 설정을 준비할 수도 있다. 정적 해상도 후보는 장치 지원을 확인하지 못했다는 안내와 함께 표시한다.
- 선택한 D405의 센서에서 `color` 스트림의 `rgb8` 프로필만 조회하고, 해상도·FPS 중복을 제거한다. 깊이/적외선이나 다른 색상 형식은 후보에 섞지 않는다. 센서 프로필 조회는 영상을 시작하거나 장치 옵션을 변경하지 않는다.
- 장치에서 조회한 목록에 기존 선택값이 없더라도 값을 바꾸지 않는다. 확인이 필요한 선택값으로 표시하고, 지원되지 않는 조합은 저장을 차단한다. 사용자가 지원 모드를 선택해야 한다.
- 조회 성공 후 지원 프로필이 0개인 경우와 조회 자체의 실패를 구분한다. 전자는 저장을 차단하고, 후자는 지원 미확인 상태의 오프라인 설정을 허용한다. 검색 실패 후에는 이전 검색 정보를 현재 지원 확인으로 사용하지 않는다.
- 명시적으로 해상도를 바꾸면 해당 해상도의 FPS 목록이 바뀐다. 기존 속도가 지원되면 유지하며, 아니면 30 fps 또는 첫 지원 속도를 고른다. 재검색이나 카메라 변경은 선택값을 임의로 바꾸지 않는다.
- SDK가 보고한 지원 모드와 실제 연결 성공은 구분한다. USB 대역폭·드라이버·장치 상태는 영상 수신을 시작할 때 최종 확인한다.

프로필 API 근거: [RealSense 공식 센서 제어 예제](https://github.com/realsenseai/librealsense/blob/master/examples/sensor-control/api_how_to.h), [공식 Python 스트림 프로필 바인딩](https://github.com/realsenseai/librealsense/blob/master/wrappers/python/pyrs_frame.cpp).

## 검색 처리와 종료

한 설정창에서 검색은 한 번만 진행하며 검색 중 저장을 막는다. UI와 분리한 조회 작업이 별도 프로세스에서 포트와 카메라를 열거한다. 기본 검색 제한 시간은 10초이며, 드라이버가 멈추면 프로세스를 정리하고 실패를 표시한다. 프로세스 정리에는 추가 시간이 소요될 수 있다. 먼저 조회한 포트 결과는 이후 카메라 오류/시간 초과가 발생해도 유지한다.

검색 중 취소·창 닫기를 요청하면 종료 안내를 표시하고 작업 정리 후 창을 닫는다. 이때 변경한 장비 설정은 저장하지 않는다. 검색 과정에는 시리얼 포트 열기, 로봇 연결 또는 모션 명령이 없다.
