# 프로그램 환경설정

운영 화면 오른쪽 위 **환경설정** 버튼을 누르면 팝업이 열린다.

| 항목 | 동작 |
|---|---|
| 표시 언어 | 한국어 / English / 简体中文(중국어 간체) / ไทย(태국어). 저장하면 재실행 없이 즉시 적용. 현재 검사·장치 연결·선택 항목 유지 |
| 글자 크기 | 100% / 115% / 130%. 저장하면 즉시 적용 |
| 시작 화면 | 실시간 검사 / 품목 설정 / 장비·보정 / 검사 이력 / VLM 추가 분석. 다음 실행부터 적용 |
| 창 크기와 위치 기억 | 정상 종료 시 창 배치를 저장하고 다음 실행에 복원. 연결된 화면 범위는 Qt의 복원 처리를 따름 |
| 저장·진단 | 운영 자료 저장 위치 확인, 해당 폴더 열기, 진단 자료 내보내기 |

**저장**은 설정을 기록하고 창을 닫는다. **취소**는 변경하지 않고 닫는다. **기본값 복원**은 팝업의 입력만 기본값으로 돌리며 저장을 눌러야 확정된다.

언어·시작 화면을 변경해도 실행 중인 프로그램을 자동 재시작하지 않는다. 검사·카메라·로봇·VLM을 켜거나 끄는 설정도 아니다. 품목별 모델/임계값은 품목 설정, 카메라/작업 영역/로봇은 장비·보정, 자료 보관 정책은 검사 이력의 저장·백업 관리에서 설정한다. 운영 자료 위치는 여기서 변경하지 않는다.

네 언어는 운영 화면, 품목/장비/보정/저장 팝업, 운영 화면에서 여는 데이터·학습/라벨링 화면, VLM 화면 및 판정 사유 표시 문구에 적용한다. 품목 이름·사용자가 입력한 메모·경로·모델 클래스·판정 코드·저장된 원본은 그대로 유지한다. 이전 기록의 설명, VLM이 생성한 문장과 외부 라이브러리/장치의 원문 오류·학습 로그는 자동 번역하지 않는다. Windows 기본 파일 선택창은 운영체제 언어를 따를 수 있다.

설정은 운영 폴더의 `preferences.json`에 별도로 저장되며 운영 백업에도 포함된다. JSON 버전과 값을 검사하고 원자적으로 교체한다. 파일이 손상되면 기본값과 안내를 표시하며, 사용자가 저장하면 손상된 파일을 별도로 보존한다. 단순 종료로 손상된 설정을 덮어쓰지 않는다. 다른 창에서 먼저 저장한 경우 오래된 설정으로 덮어쓰지 않고 다시 열도록 안내한다.

번역 자산은 `src/mes_vision/locales/en.json`, `zh-CN.json`, `th.json`에 있다. 번역 후 이름/좌표/숫자를 삽입하므로 사용자가 입력한 문자열은 번역 대상으로 검색·치환하지 않는다. 설치 배포 단계에는 모든 JSON 자산을 포함해야 한다. 시작 시 저장된 언어를 적용하며, 실행 중 저장하면 열린 화면의 번역 문구를 갱신한다. 상세 구현과 검증은 [언어 즉시 적용](LIVE_LANGUAGE.md)을 참조한다. 언어 코드는 `ko`, `en`, `zh-CN`, `th`이며 기존 한국어/영어 설정 파일도 그대로 읽는다.

Windows에서는 설치된 맑은 고딕, Microsoft YaHei, Leelawadee UI를 사용하여 한글·중국어·태국어를 표시한다. 글꼴 파일을 프로그램에 복제해 배포하지 않는다. Ubuntu에서는 설치된 Noto Sans CJK KR/SC, Noto Sans Thai를 우선 대체 글꼴로 사용한다. Ubuntu 글꼴과 화면은 아직 별도 검증하지 않았다.

검증: 기존 전체 회귀 시험, 네 언어 저장/선택, 설정 충돌/손상/실패/창 배치 병합, 번역 키와 숫자 서식 일치, 실제 Qt 팝업 저장/취소와 기본 버튼 번역, 130% 표시 및 새 프로세스의 언어/시작 화면 재적용. 중국어 번역의 한자 507자와 태국어 문자 56자가 선택 글꼴에 포함되는지도 검사한다. 실제 장비를 연결하거나 모델을 실행하지 않았다. 기존 결과는 `artifacts/preferences-check`, 중국어·태국어 추가 결과는 `artifacts/languages-check`에 보존한다. 언어별 전문 용어에 대한 현지 사용자 검수는 별도다.
