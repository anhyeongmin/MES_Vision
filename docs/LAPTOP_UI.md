# 노트북 화면·검사 이력 조회 개선 · 8번

2026-09-07. 작은 창과 큰 글씨에서 운영 화면을 사용할 수 있도록 메뉴, 동작 버튼, 스크롤 및 이력 검색 조건을 정리했다.

## 화면 배치

- 창 너비와 글씨 배율에 따라 왼쪽 메뉴를 상단 선택 메뉴로 전환한다. 두 메뉴는 같은 페이지 선택을 공유하며, 기존 바로가기로 이동해도 상단 선택이 맞춰진다.
- 프로그램 시작 시 저장된 창 크기와 위치를 현재 모니터의 사용 가능한 영역 안으로 조정한다. 기본 최소 크기는 960×600이며, 이보다 작은 사용 영역에서는 해당 영역에 맞춘다. 운영체제 창 테두리도 크기에 반영한다.
- 다섯 운영 페이지는 내용이 부족한 공간 밖으로 잘리지 않도록 스크롤할 수 있다. 품목·장비·운영 동작 버튼은 공간에 따라 다음 줄로 배치한다. 표는 많은 열과 행을 스크롤해서 볼 수 있다.
- 상단 공통 **로봇 정지** 버튼은 현재 페이지와 본문 스크롤 위치에 관계없이 사용할 수 있다. 기존 로봇 정지 처리를 호출하며, 별도 연결이나 운전 시작 동작을 추가하지 않는다.
- 작은 창에서는 준비 상태 요약을 표시하고 상세 카드는 처음에 접는다. 사용자가 직접 펼침/접기를 선택한 뒤에는 크기 변경 때문에 선택을 바꾸지 않는다. 준비 검사와 시작 차단 조건은 그대로 실행한다.
- 작은 창의 검사 이력 표 높이를 줄여 이미지와 판정 이유가 차지하는 공간을 확보한다. 화면 공간에 따라 하단 컨트롤은 스크롤로 접근한다.

## 검사 이력 검색

자주 쓰는 검색어와 판정 조건은 기본 화면에 둔다. **상세 검색 조건**을 펼치면 품목·불량 유형·검토·VLM·로봇·보존 및 기간 조건을 설정할 수 있다. 접어도 설정값은 유지한다.

**적용된 검색**은 현재 표시된 결과에 실제로 사용한 조건을 보여준다. 입력만 바꾼 경우에는 별도 문구로 아직 적용되지 않았음을 알린다. 검색어 입력 중에는 데이터베이스를 반복 조회하지 않으며 **조회** 또는 Enter로 적용한다. **조건 초기화**는 접힌 상세 조건과 기간 지정까지 지우고 전체 조건으로 한 번 조회한다. 긴 검색 조건과 전체 추적/검사 ID는 툴팁에서도 볼 수 있다.

새 검색 또는 페이지 이동을 요청하면 이전에 선택했던 이미지·판정 상세를 비운다. 새 결과에서 물체를 선택해야 해당 근거가 표시된다. 단순 주기 갱신이나 같은 원본의 보존 처리에서는 기존 선택과 원본을 유지한다. 결과가 없으면 조건에 맞는 이력이 없다고 표시한다. 표의 정상/불량/보류 표시는 선택한 언어로 번역하며 저장된 판정 코드는 변경하지 않는다.

뒤늦게 끝난 이전 조회의 결과와 오류는 최신 조회를 덮어쓰지 않는다. 새 조회가 실패했다면 이전 결과를 새 조회 결과처럼 내보내지 못하도록 확인한다. 입력 중인 조건이 아직 적용되지 않은 경우 내보내기는 화면의 **적용된 검색** 결과를 기준으로 한다. 잘못된 기간은 기존 적용 조건을 변경하기 전에 거부한다.

기존 100건 페이지 조회, 비동기 처리, 변경된 표 셀만 갱신하는 방식, 검사·로봇 감시 주기와 저장 원본 검증은 유지한다.

## 검증

관련 UI 시험 51개를 먼저 통과한 뒤 작은 화면의 준비 패널 기본 접기와 표 높이를 보완했다. 신규 시험은 11개이며 메뉴 동기화, 960×640/130% 글씨의 페이지·정지 버튼 접근, 버튼 줄바꿈, 사용자 패널 선택 보존, Enter 조회와 입력/적용 구분, 전체 조건 초기화, 잘못된 기간 거부, 오래된 상세 초기화, 이전 조회 오류 무시 및 내보내기 조건을 확인한다.

한국어·영어·중국어·태국어마다 다음 7개 화면을 렌더링했다.

- 960×640, 130% 글씨: 실시간 검사·품목·장비·검사 이력·VLM의 5개 페이지
- 같은 크기에서 상세 검색 조건을 펼친 검사 이력
- 1440×900, 100% 글씨의 큰 창

총 28개 화면에서 창 크기, 상단 정지 버튼 접근, 스크롤 범위를 확인했다. 최종 한국어 실시간 화면과 태국어 검사 이력 화면을 시각 확인했다. 임시 시험 자료를 사용했으며 장비를 연결하거나 로봇을 움직이지 않았다.

실제 노트북의 디스플레이 배율, 멀티 모니터 이동, 카메라 영상과 로봇 연결 상태에서의 장시간 운영은 현장 검증 항목으로 남아 있다. 설치·배포는 기존 계획대로 실물 검증 후 진행한다.
