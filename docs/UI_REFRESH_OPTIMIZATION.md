# 화면 갱신 개선 · 1번

2026-09-07. 전체 420개 회귀 시험 통과 (85.261초). 관련 시험 62개를 먼저 확인한 뒤, VLM 완료 결과 표시 시험을 추가해 전체 검증했다.

## 변경

- 상단 VLM 상태만을 위한 자동 DB 조회를 40ms마다 실행하던 경로에서 정상 시 1초 간격으로 변경했다. 오류 시 5초 후 재시도한다. 표시 중인 VLM 페이지에서 상태를 받으면 상단에도 즉시 반영하므로 별도 상태 조회를 미룬다.
- 상단 상태와 VLM 목록의 주기적 DB 읽기는 GUI 밖에서 수행한다. 각 조회기는 한 번에 하나만 실행하며, 느린 응답 때문에 조회 작업이 쌓이지 않는다.
- VLM 페이지가 숨겨져 있으면 주기적 목록/요약 조회를 생략하고, 다시 표시될 때 조회한다. 페이지 이동 및 ON/OFF 이후 오래된 응답이 화면을 덮어쓰지 않도록 조회 세대를 무효화한다.
- VLM 표와 검사 이력 표는 기존 셀을 재사용하며 표시 내용이 바뀐 셀만 수정한다. 선택은 물체/요청 ID를 기준으로 유지하고 스크롤 위치를 보존한다. 같은 내용은 표를 다시 구성하지 않는다.
- 동일한 VLM 자료의 반복 갱신에서 저장 근거를 다시 읽지 않는다. 목록이 비면 이전 물체의 상세 정보를 지운다. 보관 경로가 바뀌면 상세 근거 캐시를 갱신한다.
- 카메라/로봇/검사 프로세스 상태 감시는 기존 40ms 주기를 유지한다. 종료 시 진행 중인 읽기가 끝날 때까지 기다리되, 늦은 응답은 적용하지 않는다.

## 검증

새 회귀 시험 11개는 반복 조회 억제, 지연된 DB와 GUI 이벤트/로봇 감시 병행, 오래된 ON 응답 무시, 종료 중 조회 정리, 변경 없는 200행 표의 셀 변경 신호 0회, 새 행 삽입 후 선택 ID 보존, 숨긴 페이지의 조회 생략, 페이지 재진입 시 최신 상태, 불필요한 근거 재읽기 방지, 빈 목록의 상세 제거, VLM 완료 후 기본 검사 근거 보존을 확인한다.

기존 시험에서는 비동기 조회가 완료된 뒤 오류 표시와 종료를 확인하도록 대기를 추가했다. 기존 오류 차단/기본 검사 유지 조건은 유지했다. 원본 소스 해시와 검증 로그는 `artifacts/ui-refresh-step1`에 보관한다.

## 범위와 한계

이번 변경은 8개 개선 중 1번이다. VLM 모델 유지 정책, 진행 상태 문구, 장비 선택 방식, 영상 확대 등 2~8번은 별도 작업이다. 자동 반복 조회를 비동기화했으며 명시적인 상세 열기/사용자 작업의 파일 읽기와 DB 쓰기 전체를 비동기화한 것은 아니다. VLM 목록은 표시 중에는 기존 0.5초 간격으로 확인한다.

이 결과는 소프트웨어 회귀 검증이며 실제 카메라·로봇 연결, 노트북에서의 실시간 병행 부하, 장시간 운전 및 실제 판정 지연은 검증하지 않았다. 테스트의 처리 시간은 앱 성능 향상률이나 검출 속도를 의미하지 않는다.
