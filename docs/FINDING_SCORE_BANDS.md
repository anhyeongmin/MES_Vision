# 검출 점수 표시 구간

`finding-display-v1`은 화면 표시와 현재 2B VLM 영역 선택 규칙입니다. 실제 불량 확률이나 검증된 최종 합격/불합격 기준이 아닙니다.

- 0.5 이상: `[검출]`, 붉은색 표시선/상세 항목
- 0.2 이상, 0.5 미만: `[의심]`, 노란색 표시선/상세 항목
- 0.2 미만: 기본 목록·표시선·VLM 대상에서 제외, 원본 스냅샷의 검출 기록 유지
- 점수가 없는 NG01~NG06 근거: 의심으로 표시. 다른 검사 종류의 근거를 임의로 삭제하지 않음

최고점과의 상대적 차이로 제거하지 않습니다. 여러 불량이 각 기준을 통과하면 모두 유지합니다. 예: NG05 0.948 + NG06 0.133은 NG05만 표시하며, NG06 0.33이면 의심으로 함께 표시합니다.

수동 도착 검사, 저장사진 검사, 공통 상세 근거와 표시선에 적용됩니다. 원본 점수·영역·최종 판정·좌표계는 변경하지 않습니다. 현재 미검증 수동검사 결과는 계속 보류이며, 의심만 있거나 표시할 불량이 없더라도 자동 OK 처리하지 않습니다. 실제 운전의 검증된 판정 정책을 이 표시 규칙으로 대체하지 않습니다.

VLM은 검출과 의심 영역을 모두 받을 수 있고, 결과에도 해당 구분을 붙입니다. 낮은 점수만 있어 영역이 제외된 경우 정상 관찰 요청으로 바꾸지 않습니다. 영역 좌표 검증은 숨김 처리 전에도 수행합니다. 기존 저장 VLM 설명은 과거 기록이며 자동 재생성하지 않습니다.

새 사진 검사 스냅샷에는 표시 규칙 버전을 기록합니다. 화면은 현재 표시 기준으로 과거 검출 기록도 표시할 수 있습니다. 임계값은 실물 평가로 조정할 대상입니다. 재학습이나 모델 다운로드는 필요하지 않습니다.
