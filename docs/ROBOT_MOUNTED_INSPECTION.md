# 로봇 장착 카메라 검사로 전환

> 2026-09-09 최신 상태: 기본 실행 파일과 검사 시작을 새 전체·상세 회차 실행기에 연결했다. 저장된 전체사진·선택 물체의 상세사진·기본 이유·VLM 설명 화면, 촬영 저장 프로세스 감시, 로봇 운전 프로필, 새 회차 목록과 백업/복원도 연결했다. **선택적 OK·NG 분류 이송까지 연결했다. 새 회차의 기존 검색·CSV·수동 검토·보존 정책도 통합했다.** 실제 장비를 구동해 검증하지 않았다. 분류 사용법은 [STATION_SORTING.md](STATION_SORTING.md), 이력·보관 사용법은 [STATION_HISTORY.md](STATION_HISTORY.md)를 참고한다. 현행 사용법과 범위는 [STATION_OPERATION.md](STATION_OPERATION.md)를 따른다.

아래 내용은 이전 구현 단계의 기록이다. 당시의 ‘다음 작업’ 및 검사 수는 그 단계 기준이며 위 최신 안내가 우선한다.

## 확정한 제품 동작

카메라는 그리퍼 회전부를 피해서 장착하고 렌즈는 작업대를 내려다본다. 로봇이 전체 촬영 위치로 이동하여 정지한 뒤 전체사진을 저장한다. 전체사진은 위치를 찾는 용도다. 물체별 촬영 위치로 이동하여 정지·안정화를 확인하고 상세사진으로 기본 판정을 수행한다. 검사 중 물체는 움직이지 않는 조건이다.

전체 촬영 → 위치 검출 → 좌표 변환 → 물체별 근접 촬영·판정 → 결과 표시 → 분류 이송 순서다. 모든 물체의 상세 검사를 마친 후 분류하며, 보류는 자동 분류하지 않는다. 연속 추적이나 사진 이어 붙이기는 기본 흐름에 포함하지 않는다. 검사 중단·장면 변경·카메라 재연결 후에는 이전 좌표로 이어서 움직이지 않고 새 회차의 전체사진이 필요하다.

왼쪽은 저장한 전체사진과 물체별 결과, 오른쪽 위는 선택 물체의 상세사진, 오른쪽 아래는 기본 판정 이유와 VLM 설명이다. 화면 선택은 추적 ID가 아니라 검사 회차 ID와 물체 ID로 연결한다. 전체사진 좌표와 상세사진의 불량 위치는 별도 좌표계다.

VLM은 저장된 상세사진과 기본 검사 결과로 보조 설명을 만든다. ON/OFF를 제공하고, 꺼져 있거나 설명이 도착하지 않아도 기본 판정과 불량 종류를 표시한다. VLM은 판정과 로봇 분류의 선행 조건이 아니다.

## 이번에 구현한 범위

**2026-09-09 후속 변경: 촬영·보정 설정창과 D405/Magician용 촬영 연결 모듈을 추가했다.** 운영 화면의 `장비 · 보정 → 로봇 촬영 설정`에서 확인할 수 있다. 아래 1차 핵심 모듈에 이어진 작업이며, 기존 `검사 시작` 버튼은 아직 새 회차 실행기와 연결하지 않았다. 새 전체/상세 운영 화면, 분류 이송 연결, VLM 큐·이력 통합이 남아 있다. 설치된 장비 없이 실제 이동·촬영이나 모델 성능을 검증했다는 뜻이 아니다.

후속 변경의 설정 방법과 구현·검증 범위는 [ROBOT_CAMERA_SETUP.md](ROBOT_CAMERA_SETUP.md)에 정리했다.

**1차 변경: 모델 교체 구조와 새 검사 순서의 핵심 모듈. 현재 실행되는 운영 화면과 실제 장치 명령은 아직 새 순서로 전환하지 않았다.**

- 기존 `operation.engine.Models`의 물체·불량 모델 생성을 `inspection.model_registry`로 분리했다. 기존 등록은 RF-DETR Small을 사용한다. 등록된 다른 공급자는 동일한 Detector/Inspector 결과 형식으로 교체할 수 있다. 이상 탐지도 명시적인 backend 등록으로 교체 가능하며 기존 DINO 방식은 유지한다.
- `station.models.StationModels`는 전체 검출 모델과 상세 검사용 모델 묶음을 별도로 소유한다. 각 역할의 학습·기준 자료가 전체 촬영용인지 상세 촬영용인지 명시해야 한다. 과거 고정 카메라 자료를 자동으로 근접 검사 검증 자료로 인정하지 않는다.
- `station.vision.StationVision`은 전체사진에서 위치만 반환한다. 겹치거나 검사 영역을 벗어나는 물체를 삭제하지 않고 확인 대상으로 남긴다. 상세사진에서 하나의 해당 품목이 중심 허용 영역에 확인되어야 기본 검사를 수행한다. 모호함·화질 부적합은 보류이며 불량 모델 호출을 생략한다.
- 상세사진에 기존 알려진 불량·이상 탐지·형상 검사와 검증된 판정 정책을 적용한다. 모델 클래스 번호 대신 품목 라벨로 전체/상세 모델을 연결하여 클래스 순서가 다른 모델도 사용할 수 있다.
- `station.sequence.ScanSequence`는 이동 완료 → 안정화 → 새 프레임 저장 → 검출/검사 완료를 하나씩 확인한다. 요청마다 회차·물체·세대·요청 ID와 기한이 있으며 늦거나 중복된 응답으로 다음 동작을 시작하지 않는다.
- `station.evidence`는 전체/상세 원본을 새 폴더에 보존한다. 검사 결과를 채택할 때 저장된 상세사진의 픽셀, 원본 식별값, 물체 연결, 품목, 판정 정책 식별값을 확인한다. 전체사진으로 OK/NG를 만들 수 없다.
- `ScanJournal`은 별도 `station.sqlite3`에 회차·단계·요청을 원자적으로 기록한다. 기록 실패 시 다음 요청을 반환하지 않는다. 중단된 회차는 재시작 시 INTERRUPTED로 남기며 요청을 자동 재전송하지 않는다. 기존 운영 자료와 추적 이력을 임의 변환하지 않는다.
- VLM 설명은 별도 테이블로 연결하며 기본 판정 자료를 변경하지 않는다.

실제 공급자로 새로 구현·다운로드한 모델은 없다. RF-DETR Small을 현재 기준 모델로 유지했다. 새 아키텍처는 실제 구현, 정확한 버전/가중치의 라이선스 확인, 성능 평가, 그 모델에 맞는 판정 기준 검증을 거쳐 등록한다. 공급자에 적은 라이선스 메타데이터만으로 상업 사용 조건이 검증되는 것은 아니다.

## 이어서 연결할 작업

1. **촬영 설정과 보정:** 전체 촬영 자세, 상세 촬영 거리/검사면 높이, 카메라 장착 링크와 자세 변화, 카메라·집게 위치 관계, 이동 경로·여유 높이의 등록 및 검증. 이동 카메라용 좌표 변환을 구현한다. 기존 고정 카메라 보정 파일은 재사용하지 않는다.
2. **장치·검사 실행 연결:** 시퀀스 요청을 현재 D405·Magician·검사 프로세스에 연결한다. 단순 명령 접수와 실제 도달 완료를 구분하고, 정지 버튼은 기록/모델 작업과 독립적으로 로봇 정지를 요청해야 한다. 재시작 복구는 프로그램의 배타적 실행 권한을 확보한 다음 수행한다.
3. **새 운영 화면:** 확정된 전체/상세 배치, 회차 진행률, 물체 선택, 상세 판정·VLM 설명, 설정 팝업과 다국어를 연결한다. 카메라 미리보기가 저장된 전체사진을 덮어쓰지 않게 한다.
4. **이력·백업·VLM 연결:** 새 회차를 현재 이력 검색·보존·백업에 포함하고, 상세사진의 기본 결과가 저장된 뒤 기존 VLM 큐에 전달한다. 새 시퀀스의 별도 VLM 설명 저장 기능은 아직 큐의 자동 실행과 연결되지 않았다.
5. **실물 평가:** 전체 검출 누락과 좌표 오차, 근접 화질, 기본 판정의 불량 통과·오탐·보류, 전체 처리 시간을 3090에서 평가하고 노트북에서도 확인한다. 이 결과를 기준으로 모델을 교체한다.

장비가 없어도 설정 구조·장치 명령 연결·UI 및 저장 기능은 개발할 수 있다. 실제 장착 수치, 로봇 가동 범위, 보정 오차, 촬영 거리, 조명, 모델 정확도와 운전 성능은 실물로 검증해야 한다. 현재 코드는 해당 값을 추정해서 채우거나 실제 로봇에 이동 명령을 보내지 않는다.

## 핵심 모듈 연결 계약

`ScanSequence.start(profile, monotonic_time)` 또는 `tick/complete`가 반환한 요청은 저장 완료 후 한 번만 전달한다. 요청 종류는 `move_overview`, `capture_overview`, `detect_overview`, `map_targets`, `move_detail`, `capture_detail`, `inspect_detail`, `sort_object`다. `None`을 반환하면 새 명령이 없으며 상태를 읽어 대기/완료/실패를 구분한다.

이동 응답은 측정 자세와 실제 완료 증거를 포함한다. 촬영 응답의 `acquired_at`은 안정화 이후 새 촬영 요청보다 늦은 동일 호스트 단조 시각이어야 한다. 큐에 남은 프레임의 수신 시각을 새 노출 시각으로 바꿔 적어서는 안 된다. 실제 카메라 어댑터에서 새 프레임의 세션/순번과 촬영 시점을 확인해야 한다.

좌표 변환 응답은 전체 검출과 같은 물체 ID 집합, 고정한 보정 식별값, 검증된 촬영 자세와 집기 자세를 반환한다. 현재 핵심 모듈의 좌표 범위 검사는 로봇 역기구학·충돌 없는 경로 검증을 대체하지 않는다. 해당 검증과 실제 카메라 장착 구조에 맞는 변환은 다음 장치 연결 단계의 필수 작업이다.

검사는 `StationVision.inspect_detail` → `save_detail` 순서로 처리한 영수증을 반환한다. `sort_object` 요청은 완성된 로봇 명령이 아니라 검증된 분류 계획을 생성하기 위한 요청이다. 로봇 어댑터는 경로, 도달, 집기·놓기 확인을 거쳐 완료를 알려야 한다.

## 검증

2026-09-09 전체 자동 검사 **562개 통과**. 이 중 새 검사 구조·모델 교체 관련 검사는 **35개**다.

새 테스트는 실제 장비 대신 명시적으로 주입한 결과로 순서와 계약을 검사한다. 실물 모델의 정확도·속도 결과로 해석하지 않는다. 전체 검출에서 상세 검사 모델을 호출하지 않는지, 상세 NG/보류 판정, 다른 클래스 순서, 두 물체 검사 후 분류, VLM 비권한성, 중단·재시작·기한 초과·중복 응답·카메라 변경·원본 변조·판정 정책 변경·저장 실패를 포함한다.

검증 로그와 배포한 파일의 식별값은 `artifacts/station-core/`에 보존한다.
