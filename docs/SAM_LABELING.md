# SAM 라벨링 보조

SAM 2.1 Small을 사진 라벨 초안 제작에만 사용한다. 실시간 검사·최종 OK/NG 판정·집기 위치 계산에는 연결하지 않는다. 기존 RF-DETR은 상자 라벨을 학습하므로 SAM의 마스크를 원본 이미지 좌표의 외곽 상자로 변환한다. 학습 이미지의 배경을 마스크로 지우는 기능은 아니다.

## 사용 순서

1. **품목 설정 → 데이터 · 학습 → 데이터 수집·라벨링 열기**에서 수집 프로젝트를 연다. 독립 실행은 `scripts/label_data.py --workspace collections/ash-real-detail-v1`이다.
2. 사진을 가져오거나 영상에서 추출한 사진을 선택한다.
3. **SAM 물체 라벨**을 누른다. 포함할 부분을 클릭하거나 **상자 지정**으로 물체 주위를 그린다.
4. **마스크 생성**을 누른 뒤 후보를 비교한다. 배경이나 그림자가 포함되면 **제외 클릭**을 추가하고 다시 생성한다. 여러 포함 클릭도 가능하다. 잘못 넣은 입력은 초기화할 수 있다.
5. **선택 마스크 적용** 후 실물 ID를 입력한다. 물체 상자가 초안에 추가되며 관찰 상태는 미검토다. 같은 실물에는 다른 사진에서도 같은 ID를 사용한다.
6. 필요하면 기존 상자 수정 기능으로 고친다. 정상/불량 상태와 영역을 확인하고 저장·검토 완료한다.

**SAM 불량 영역**은 먼저 물체와 불량 코드를 선택한 뒤 사용한다. 선택한 마스크가 물체 상자 밖으로 나가면 적용하지 않는다. 사용자가 지정한 코드로 영역 초안을 추가할 뿐, SAM이 NG 종류를 판별하지 않는다. 균열·누락 위치·반사처럼 분할이 어려운 경우 기존 수동 상자나 영역 없는 관찰을 사용한다.

SAM 점수는 마스크 품질에 대한 모델의 추정값이며 정답 확률이나 불량 판정 점수가 아니다. 가장 높은 점수의 후보에도 그림자가 포함될 수 있다. 적용 버튼을 누르는 것과 라벨 검토 완료는 별개다. SAM 기능은 검토 완료나 학습 실행을 자동으로 수행하지 않는다.

## 실행·저장

- 모델은 `models/sam2.1-hiera-small/`의 공식 Meta 체크포인트를 오프라인으로 읽는다. 설치된 Transformers를 사용하며 패키지 교체는 하지 않았다.
- SAM 작업마다 별도 Python 프로세스를 실행하고 종료 후 GPU 메모리를 반환한다. 모델 초기화 때문에 첫 반응에 시간이 걸릴 수 있다. 현재 이미지 임베딩을 여러 실행 사이에 상주시켜 재사용하지 않는다.
- 취소 버튼·창 닫기로 자식 프로세스를 종료한다. 180초 제한을 넘겨도 취소 처리하며, 취소 결과를 라벨로 적용하지 않는다.
- 해당 운영 폴더의 GPU·상주 모델 잠금을 사용한다. 운영 모델은 해제한 뒤 사용하고, 별도 학습 작업과 동시에 실행하지 않는다. 사용자 지정 운영 폴더를 독립 라벨러에서 쓰려면 `--runtime`도 같은 경로로 지정한다.
- 적용한 마스크와 프롬프트·모델 출처는 수집 폴더의 `assists/`에 보존하고 물체/불량 라벨에 연결한다. 라벨 취소·삭제 후에도 이 파일은 자동 삭제하지 않는다. 전체 수집 폴더를 백업한다.
- 물체 상자를 이후 수동 수정하면 저장된 마스크와 모양이 달라질 수 있다. `original_box`는 SAM 적용 당시 상자이며 학습에는 최종 검토한 `bbox`가 사용된다.
- 사진 추가/영상 추출은 기존 기능을 사용한다. 이번 범위에는 영상 전체에 마스크를 전파하는 추적 기능이나 DETR 예측 일괄 라벨 가져오기는 포함하지 않았다.
