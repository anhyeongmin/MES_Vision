# MES Vision 로봇 제어 · 티칭

`MES Vision.cmd`를 실행하고 왼쪽 **로봇 제어 · 티칭** 메뉴(F6)를 누른다.
로봇 기능은 메인 화면의 페이지 안에 표시되며 별도 티칭 팝업을 열지 않는다.
별도 티칭 프로그램을 실행하지 않는다. MES Vision 안에서 카메라 확인·로봇 연결·저장·시험 이동을 모두 진행한다.
이미 실행 중이면 `MES Vision.cmd`를 다시 눌러 기존 창을 앞으로 가져온다.
모델을 해제하고 자동운전용 로봇 연결을 해제한 상태에서 티칭을 연다.
시작만으로 연결, 이동, Homing, 집게 작동을 하지 않는다.

## 축 제어

1. 이 페이지에서 COM 포트를 선택하고 **로봇 연결**을 누른다.
2. **축 제어**에서 **X / Y / Z / R** 또는 **J1 / J2 / J3 / J4**를 선택한다.
3. 장착물과 실제 가동 범위를 확인해 각 축의 허용 최소·최대값을 입력한다.
4. 빈 집게, 손과 Unlock 해제, 현재 경로를 확인하고 직접 제어 허용을 체크한다.
5. ± 버튼은 실측 현재값 기준으로 1회 이동한다. 기본 1 mm/도, 선택 범위 0.1~5 mm/도이며 누르고 있어도 반복하지 않는다.
6. 목표 수치를 입력한 뒤 **이 축 이동** 또는 **네 축 입력값으로 이동**을 누르고 목표를 확인한다.
   수치 입력과 **현재값을 목표칸에 채우기**만으로는 움직이지 않는다.

XYZR은 도봇 base 좌표와 회전각, J1~J4는 GetPose가 반환하는 실제 관절각이다. R과 J4를 같은 값으로 간주하지 않는다.
XYZR은 MOVL 직선 이동, 관절각은 MOVJ_ANGLE로 실행하고 큐 완료 및 실제 각도/좌표를 확인한다.
직접 축 제어는 저장한 이동 높이를 거치지 않는다. 조인트 궤적은 Cartesian 직선이 아니며 작업판·카메라 충돌을 자동 계산하지 않는다.
조인트 제어에서는 관절 허용 범위를 확인한다. Cartesian 허용 사각형이 조인트 궤적을 보증하는 것은 아니다.
속도는 기본 5, 최대 10 mm/s 또는 °/s다. 속도/가속도를 설정하고 읽어 확인한 후 움직인다.
낡은 연결·응답, 이동 중 요청, 범위 밖 목표, 비정상 수치는 거부한다. 재연결·정지·탭 변경 후 직접 제어 허용을 다시 체크한다.
다른 왼쪽 메뉴로 나가거나 메인 상단 **로봇 정지**를 누르면 진행 중인 수동 이동을 정지한다.
앱 종료 시 로봇 worker 종료를 기다린다. 로봇 제어 탭이 연결된 동안 자동 검사 시작과 자동운전용 중복 연결을 차단한다.

프로토콜 근거: [Dobot Magician Communication Protocol V1.1.5](https://download.dobot.cc/product-manual/dobot-magician/pdf/en/Dobot-Communication-Protocol-V1.1.5.pdf), GetPose, PTPJointParams, PTPCoordinateParams, PTPCmd.

## 위치 등록

같은 페이지의 **위치 티칭 / 카메라** 탭으로 전환한다.

1. 도봇 COM 포트를 선택하고 **로봇 연결**을 누른다. 연결 시 정지·큐 초기화와 위치 확인을 수행한다.
2. 실제 Magician의 Unlock 버튼을 사용해 손으로 위치를 배치하고 손과 버튼을 놓는다.
3. 해당 **저장** 버튼을 누른다. worker가 위치를 새로 두 번 읽어 안정 상태를 확인한 후 저장한다.
4. HOME, 풀뷰, 상세 촬영, 집기, OK/NG 목적지와 이동 높이를 등록한다.
5. 작업판 네 모서리는 같은 집게 기준점으로 좌하단 → 우하단 → 우상단 → 좌상단 순서로 등록한다.

HOME은 사용자가 정한 대기 자세다. 장비 Homing이나 base 원점 재설정이 아니다.
정지·응답 시각과 X/Y/Z/R을 표시하며, 오래된 응답에서는 저장/이동을 차단한다.
네 모서리는 초안이며 기구학적 도달 범위나 충돌 없는 이동 영역으로 승격되지 않는다.

## 카메라 오프셋

이 설치는 **집게 R축을 돌려도 카메라가 함께 회전하지 않음**을 전제로 한다.

동일한 물리 기준점을 카메라 영상 중심에 맞추어 `오프셋: 카메라 중심 맞춤`을 저장한다.
같은 점을 집게 기준점으로 맞추어 `오프셋: 집기점 맞춤`을 저장한 다음 **두 기준점으로 카메라 오프셋 계산**을 누른다.
두 측정의 R은 같게 유지한다. 결과는 `집기점 맞춤 자세 - 카메라 맞춤 자세`이며 단위는 mm다.
ΔZ는 촬영/집기 높이 차이를 포함하므로 물리 장착 오프셋 전체를 측정했다고 간주하지 않는다.
초안 결과는 위치 이동에 자동으로 더하지 않는다. 픽셀→로봇 보정과 두 좌표 맵은 별도 실측이 필요하다.
십자선은 표시 영상의 중심이다. 광학 중심/왜곡보정 정확도까지 검증하는 기능은 아니다.

## 저장한 자세로 시험 이동

1. 빈 집게 상태에서 현재 위치와 목표 위치보다 높고 경로가 확보된 **이동 높이**를 먼저 티칭한다.
2. 실물로 확인한 X/Y/Z/R 허용 범위를 입력한다. 임의 범위나 임의 높이는 기본값으로 채우지 않는다.
3. 목록의 목적지를 선택하고 **선택 위치로 시험 이동**을 누른다.
4. 현재 XY에서 이동 높이로 상승 → 목표 XY로 직선 이동 → 목표 Z로 하강하는 세 구간을 확인한다.
5. 손·Unlock 버튼을 놓고, 집게가 비어 있고 카메라·케이블·장애물 간섭이 없는지 확인한 후 실행한다.

속도는 기본 5 mm/s, 최대 10 mm/s다. Cartesian 속도/가속도와 공통 배율을 설정하고 읽어 확인한다.
첫 시험은 현재 R과 목표 R이 1도 이내인 경우만 허용한다. 실제 기구학적 도달 가능성과 장애물 회피는 자동 계산하지 않는다.
범위 확인은 이동 높이와 목적지를 포함한 세 구간에 적용하며, 단순 작업판 사각형을 자동 허용 영역으로 쓰지 않는다.
확인창 이후 현재 위치 또는 저장 위치가 바뀌면 이동을 거부한다.
각 구간의 큐 완료 번호와 실측 자세로 도착을 확인한다. 정지/통신 오류/종료 시 나머지 경로를 자동 재전송하지 않는다.
**로봇 정지**는 소프트웨어 통신 정지 요청이다. 통신 장애에서 물리 비상정지를 대체하지 않는다.

## 보존과 범위

- `artifacts/operation/robot-teaching/draft.json`과 변경별 JSON 이력에 저장한다.
- pose 원시 정밀도, 단위, 측정 시각, 연결 회차, 포트 식별값, 설치/base/tool/mount/camera/acquisition 식별값을 보존한다.
- 재실행 후 목록은 복원된다. 재연결 전 점은 **재티칭 필요**로 표시하고 다시 저장하기 전에는 이동에 사용하지 않는다.
- 저장 파일은 항상 초안이다. 검증된 자동운전 프로필이나 자동 분류 정책을 생성하지 않는다.
- 티칭 중 자동 검사를 차단한다. 종료 후 자동운전은 장비 준비 확인과 새 풀뷰 회차가 필요하다.
- 현재 단계는 빈 집게 이동이다. 물체를 든 이동, 집게 열기/닫기, 자동 픽앤플레이스 승인은 포함하지 않는다.

참조: [Dobot 공식 Magician 사용 설명서, 수동 티칭](https://download.dobot.cc/product-manual/dobot-magician/pdf/V1.7.0/en/Dobot-Magician-User-Guide-V1.7.0.pdf).

## 소프트웨어 확인

`test_teaching`은 실물 시리얼을 열지 않는 주입 장치 시험이다. 저장 시 이동 없음, 새 pose 읽기, 재연결/설치 변경,
원자 저장 실패, 오프셋 방향, 모서리 순서, 경로 범위, 정지, 포트 소유권, 오래된 UI 위치와 연결 오류를 확인한다.
테스트 통과는 실제 이동 경로 또는 실제 집기 검증을 의미하지 않는다.
