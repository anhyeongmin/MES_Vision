# 전체·상세 검사 이력과 원본 관리

2026-09-09. 새 로봇 장착 카메라 회차의 물체 결과를 기존 검사 이력 검색·검토·내보내기·보관 기능에 연결했다. 실제 운영 원본을 이동하거나 정리한 작업은 없으며, 자동 검사는 임시 폴더의 주입한 영상과 모의 결과로 수행했다.

## 이력 화면

`검사 이력`에서 이전 연속 검사 기록과 새 전체·상세 검사 결과를 함께 조회한다. 물체·검사·회차 ID, 품목 이름, 기간, OK/NG/보류, 불량 코드, 검토 여부, VLM 상태, 로봇 상태, 보존 상태를 검색할 수 있다. 기존 100건 단위 페이지와 전체 조건 내보내기를 유지한다.

새 회차의 검사 시각은 전체 회차 시작 기록의 시각이다. 물체 ID는 회차 안에서 부여한 ID이며, 사진을 추적한 ID가 아니다. 첫 검사의 기본 판정을 한 행으로 표시하고 이송 상태를 별도로 보존한다. 현재 구조에서는 다른 회차를 같은 실물 물체의 재검사로 자동 연결하지 않는다.

선택한 행의 상세사진과 기본 이유를 확인한다. 상세사진이나 유효한 상세 판정이 없는 보류 물체도 목록에서 빠지지 않는다. 이 경우 확보된 사진과 위치 확인·상세 확인 사유를 표시하며 정상/불량 결과를 만들어내지 않는다. `선택 이력의 전체·상세 결과`로 저장된 전체사진과 선택 물체의 상세 결과를 함께 볼 수 있다. 검사 진행 중에는 운영 화면을 과거 회차로 전환하지 않는다.

`최근 회차 목록`을 펼치면 결과가 없는 중단 회차를 포함해 최근 100개 회차를 확인할 수 있다. 이 보조 목록의 100개 제한은 물체 결과 검색의 페이지 제한과 별개다. 결과가 전혀 없는 회차는 물체별 검사 건수에 포함하지 않으며 회차 DB에 계속 보존한다.

## 검토와 VLM

검토 기록은 확인자·내용·시각을 남기고 목록을 갱신한다. 최신 메모를 화면에 표시하고 이전 검토는 이벤트 기록에 남긴다. 검토는 기본 판정·정책·사진·이송 기록을 바꾸지 않으며, 보류를 OK로 변경하거나 로봇을 다시 움직이는 기능이 아니다.

이력에서 VLM을 요청하면 저장된 상세 검사 물체 ID를 사용한다. 새 회차의 선택 물체와도 설명을 연결한다. 유효한 상세 검사 근거가 없는 보류는 수동 VLM 요청을 차단한다. VLM OFF 또는 설명 미완료 상태에서도 기본 이유를 확인할 수 있다. 이력 화면에서는 로봇 동작을 실행하지 않는다.

## 검색 결과 내보내기

현재 적용된 검색 조건 전체를 CSV·JSON으로 내보낸다. 현재 보이는 한 페이지만 내보내는 방식이 아니다. 기본 판정·불량 코드·검토 메모·VLM 상태와 응답·이송 상태 및 저장된 이송 근거를 포함한다. CSV에는 기록 방식과 회차 ID도 추가했다.

`원본 포함`을 켜면 일치하는 물체의 전체사진·상세사진·상세 검사 근거를 함께 복사한다. 같은 전체사진은 한 번만 복사하며, 검색에서 제외한 다른 물체의 상세 근거를 추가로 복사하지 않는다. 전체사진에는 촬영 당시 다른 물체도 함께 보일 수 있다. JSON의 새 회차 이미지 참조는 내보내기 폴더 기준 상대 경로다. 내부의 기존 검사 스냅샷은 원래 내용을 유지한다.

사진을 제외해도 기본 이유와 기록을 JSON에 포함한다. 원본이 변경되거나 없으면 정상 내보내기로 처리하지 않는다. 실패한 중간 폴더는 임의로 삭제하지 않으며 최종 폴더 이름으로 완료 처리하지 않는다. CSV의 수식으로 해석될 수 있는 문자열 보호와 파일 식별값 검증을 유지한다.

## 회차 단위 보존

전체사진은 여러 물체가 공유하므로 **새 회차는 사진 묶음 전체를 한 단위로 보관**한다. 같은 회차의 물체 중 가장 긴 보존 기간이 끝나야 이동 후보가 된다. `별도 보존` 역시 회차 전체에 적용된다.

다음 회차는 보관 이동에서 보호한다.

- 진행 중인 회차, 중단·실패한 회차, 검사 결과가 없는 회차
- 이송 결과를 확인해야 하는 회차, 별도 보존 지정 회차, 복원 후 보호된 회차
- 보호 설정이 켜진 미검토 보류·미등록 이상, 색인을 만들 수 없는 손상 자료
- 물체 하나라도 해당 판정의 보존 기간이 끝나지 않은 회차

저장 관리의 미리보기에서 후보·보호 사유를 확인한 뒤 보관 이동을 실행한다. 기능 추가만으로 기존 원본을 자동 이동하거나 삭제하지 않는다. 모델·로봇·VLM 작업과 회차가 종료되어야 실행할 수 있다.

보관 위치에 전체·상세 원본을 복사하고 파일 식별값을 검증한 다음 회차와 VLM의 경로를 연결한다. 이 과정이 끝난 뒤에만 운영 폴더에서 목록에 있던 중복 파일을 정리한다. 경로는 운영 폴더의 관리 대상 바로 아래로 제한하고 링크·접합점·추가 파일·변경 파일을 거부한다. 중간에 끊기면 기존 보관 복구 기능으로 완료 여부를 재확인한다. 기본 판정이나 과거 이벤트 내용은 다시 쓰지 않는다.

새 원본 폴더의 용량을 저장 관리의 검사 원본 용량에 포함한다. 회차에 연결되지 않은 중간 저장물, 결과 없는 회차, 실패한 회차를 자동 삭제하는 기능은 추가하지 않았다. 이 자료들은 조사용으로 유지한다.

## 백업과 복원

외부 보관 위치의 새 회차 원본도 백업에 포함한다. 복원 시 회차 경로를 복원본 내부로 연결하고 검토 메모를 유지한다. 검색 색인은 복원된 회차로 다시 구성한다. 기존과 같이 설치 설정·좌표 실행 권한을 복구하지 않으며 VLM과 로봇이 과거 작업을 자동 재개하지 않는다.

검색 색인은 운영 원본과 분리된 재구성 가능한 자료다. 새 회차나 상태가 바뀐 회차만 갱신하며, 색인 오류가 생겨도 이미 기록된 기본 결과 행을 삭제하지 않는다. 오류 건수와 색인 갱신 기능으로 확인할 수 있다.

## 확인한 범위

검사는 기존/새 기록 혼합 조회, 필터·페이지·검토 보존, 상세사진 없는 보류, 원본 포함 내보내기, VLM ID 연결, 보존 기간·별도 보존, 전체 회차 보관 후 조회, 보관 중단 복구, 원본 변경 거부, 외부 보관본 백업·복원, 손상 색인 보고를 포함한다. 결과와 네 언어 화면 확인 자료는 `artifacts/station-history/`에 보존한다.

전체 자동 검사 **635개 통과(161.562초)**. 신규 이력 검사 12개를 포함한다. 이후 목록 갱신·상대 경로 최종 수정에 대해 이력·저장·UI 관련 **54개를 재검증하여 통과(26.708초)**했다. 네 언어 × 두 화면 크기로 8장을 렌더링하고 한국어·태국어 화면을 직접 확인했다.

실물의 화질·좌표 오차·불량 판정 정확도·집기 센서·이동 경로·처리 시간·노트북 운전은 장비 준비 후 검증해야 한다. 설치 배포는 그 검증 이후에 진행한다.
