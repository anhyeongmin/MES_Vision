# 검사 이미지 확대·정상 기준 비교 · 개선 6번

2026-09-07. 실시간 검사 영상과 저장 이력에 확대·축소, 이동, 화면 맞춤, 원본 배율 보기와 표시선 숨김을 추가했다. 검사 이력과 VLM 화면에서 저장된 검사 물체와 당시 정상 기준 이미지를 비교할 수 있다.

## 사용 방법

- 실시간 검사 및 검사 이력의 영상에서 휠로 확대·축소하고 드래그로 이동한다. 클릭은 기존처럼 원본 이미지 좌표로 물체를 선택한다. 이동한 드래그를 물체 클릭으로 처리하지 않는다.
- **화면 맞춤**은 전체 이미지를 창 크기에 맞춘다. **1:1**은 원본 픽셀 하나를 화면 픽셀 하나로 표시하며, 고해상도 화면의 배율을 고려한다. `+`/`−` 버튼도 사용할 수 있다. 이미지에 초점이 있을 때 F, 1, +, − 단축키를 사용할 수 있다.
- **검사 표시선**을 해제하면 물체/불량 경계와 영역 표시를 숨겨 원본을 가림 없이 볼 수 있다. 표시선의 글씨와 선 두께는 이미지 확대에 따라 커지지 않는다.
- 검사 이력에서 물체를 선택한 뒤 **이미지 확대 · 정상 비교**를 누른다. VLM 화면에서도 같은 버튼으로 열 수 있으며 VLM이 OFF이거나 분석 전이어도 사용할 수 있다.
- 비교창의 **원본 전체** 탭은 해당 검사 시점 전체 영상과 선택 물체 위치를 표시한다. **정상 기준 비교** 탭은 왼쪽에 검사 물체와 기본 검사 근거 위치를, 오른쪽에 함께 저장된 정상 기준 이미지를 표시한다. 두 이미지는 각각 확대·이동할 수 있으며 배율을 각각 표시한다.

비교창은 메인 창을 막지 않는 별도 창이다. 비교 중에도 메인 검사·정지 버튼을 사용할 수 있다. 같은 화면에서 새 비교창을 열면 이전 비교창을 닫아 창 수와 이미지 메모리 사용을 제한한다. 프로그램 종료 시 비교창도 닫는다.

## 이미지와 판정 보존

표시는 원본 QPixmap과 영상 좌표 변환을 사용한다. AI 확대나 원본 파일 재저장은 하지 않는다. 원본 배율 보기에는 축소된 VLM 미리보기 대신 저장된 원본 파일을 사용한다. 확대·이동·표시선 숨김·비교창 열기는 기본 판정, 원본 이미지, 검사 결과, VLM 큐 또는 로봇 명령을 수정하지 않는다.

실시간 영상은 크기가 같으면 새 프레임에서도 확대 위치를 유지하고, 영상 크기가 달라지면 화면 맞춤으로 돌아간다. 저장 이력은 같은 물체의 새로 고침에서는 배율을 유지하고, 다른 물체를 선택하면 화면 맞춤으로 돌아간다. 이미지 밖으로 끝없이 이동하지 않도록 이동 범위를 제한한다. 보정점·작업 영역 편집에 사용되는 기존 Canvas는 변경하지 않았다.

비교창은 검사 등록/분석 요청 당시의 snapshot digest를 확인하고 저장 파일의 무결성을 검증한 후 표시한다. 현재 품목 설정의 정상 이미지를 과거 검사 기준으로 대체하지 않는다. 저장된 정상 기준의 수집 ID와 버전을 표시하며, 없는 이력은 **정상 기준 이미지가 저장되어 있지 않음**을 표시한다. 물체 영역과 불량 근거 위치는 해당 검사 물체의 원본/crop 좌표를 사용한다. 판정이 연결되기 전의 저장 자료는 ‘판정 연결 전’으로 표시한다.

이 비교는 사용자가 눈으로 확인하는 나란히 보기다. 서로 다른 촬영 배율·방향을 자동 정렬하거나 차영상으로 새 판정을 내리지 않는다. 정상 기준은 기존 저장 구조가 검사 당시 보존한 한 장을 사용한다.

## 검증

관련 UI·좌표·VLM 갱신·번역 시험 64개를 먼저 통과했다. 이후 별도 창의 비차단 동작과 판정 미연결 원본 표시를 보완했다. 최종 전체 테스트 수와 소요 시간은 아래 실행 결과 및 `artifacts/image-review-step6/summary.json`을 참조한다.

신규 시험 17개는 확대 중심 유지, 확대 후 물체 클릭 좌표, 드래그와 클릭 구분, 이미지 이동 한계, 고해상도 화면 1:1 배율, 새 프레임의 확대 유지, 원본/판정/VLM 큐 불변, 선택 물체 및 정상 기준 연결, 기준 없음 표시, 파일 변조·잘못된 검사 ID 거부, VLM OFF에서 비교 열기, 비교창을 열어도 메인 창 사용 가능, 판정 미연결 자료 표시를 확인한다.

한국어·영어·중국어·태국어 각각 비교, 원본 배율, 정상 기준 없음, 1080×720 실시간 화면의 총 16개 화면을 렌더링하고 줄바꿈 높이와 창 너비를 확인했다. 최종 한국어 비교창과 태국어 작은 실시간 화면을 시각 확인했다. 이미지와 장비 상태는 임시 시험 자료를 사용했으며 운영 이력에 등록하지 않았다.
