# 성능 개선 3 — 정상 기준 GPU 유지

2026-09-06. CUDA 정상 비교에서 기준 특징을 검사 엔진 준비 시 한 번 올려 보관하고, DINO가 만든 특징을 GPU에서 바로 거리 계산에 전달한다. 현재 물체 최대 4개 묶음 검사와 물체별 결과 연결을 유지한다.

## 변경 범위

- `ResidentNeighbors`는 검증된 기준 배열의 독립 사본을 소유한다. 엔진별로 생성하며 전역 캐시를 사용하지 않는다. 보관한 기준의 반복 정규화 검증도 제거하고, 입력 쿼리는 계속 검증한다. 다른 품목/기준이 섞이지 않고 원래 기준 파일과 해시도 바뀌지 않는다.
- DINO의 `extract_many_device`는 기존 FP32 특징을 장치에 유지한다. 학습 기준 생성·CPU 호출에서 사용하는 `extract`/`extract_many`는 기존 NumPy 출력을 유지한다. 전처리·정규화·배치 상한·특징 서명은 동일하다.
- 쿼리 256개/기준 2,048개 단위, FP32 직접 L2 거리 계산과 최초 최소값의 인덱스를 유지한다. 근사 검색이나 행렬곱 거리식으로 바꾸지 않았다. 동일 벡터와 동점 근거를 별도로 확인한다. 사용하는 연산 설정은 [PyTorch 2.9 cdist 문서](https://docs.pytorch.org/docs/2.9/generated/torch.cdist.html)의 `donot_use_mm_for_euclid_dist`다.
- 반복 기준 전송과 쿼리 특징의 GPU→CPU→GPU 왕복을 제거했다. 최종 패치 거리/참조 인덱스만 물체당 한 번씩 CPU로 옮겨 기존 판정·영역·저장 로직에 전달한다. 유효성 확인용 동기화는 남아 있다.
- CUDA 엔진 기본은 `resident`, CPU는 기존 `legacy`다. 비교 도구에서는 `distance_execution='legacy'`로 이전 경로를 명시할 수 있다. 메모리 부족이나 장치 오류가 발생하면 오류를 반환하며, 검사를 건너뛰거나 다른 방식으로 자동 대체하지 않는다.
- 운영 모델 준비 시 기준 업로드와 실제 점수 계산을 워밍업한다. 종료/품목 모델 해제 시 기준을 먼저 해제한다. 종료한 엔진은 다시 검사할 수 없다. CLI와 이전 파일 검사 경로에도 해제를 연결했다.
- 기준 2,048×384 float32의 추가 상주 공간은 3MiB이며, 현재 허용하는 최대 8,192벡터는 12MiB다. DINO 쿼리와 거리 임시 배열은 별도다. 기준·임계값·모델 식별은 유지하고 저장 근거에는 `distance_execution`을 추가한다.

## 검증

CPU 단위 검증은 거리와 최근접 인덱스의 정확한 일치, 여러 청크를 가로지르는 동점, 비연속 입력, 잘못된 특징, 독립 기준 사본, 반복 사용, 준비 실패, 종료와 해제 순서를 확인한다. 실제 CUDA 검증은 DINO 특징·거리 배열·참조 인덱스를 비교하며, 저장된 합성 기준으로 임계값 없음/OK 경계/NG 경계/보류의 판정과 영역을 확인한다.

측정 도구: `scripts/benchmark_resident_anomaly.py`. 로컬 예제 사진과 기존 합성 기준 경로를 명시한다. 공개 사진 변형 8개, 범용 RF-DETR 2개, DINO, 임의 정상 기준 2,048벡터를 사용한다. 전체 장면 검출 + 최대 4개씩 물체 검사 시간을 비교한다. 전처리·GPU 동기화를 포함하지만 촬영·추적·저장·DB·UI·VLM·로봇은 제외한다. 제품 정확도나 노트북 성능 측정이 아니다.

첫 탐색 실행 `artifacts/inference-optimization/step3/gpu`는 단일 물체 경로의 워밍업 누락으로 첫 RF-DETR 호출에 준비 비용이 포함됐다. 해당 기록을 보존하며 최종 성능 수치는 모든 배치 모양을 준비한 후 실제 프로젝트에서 다시 측정한다. 결과는 `deployed-gpu/report.json`과 `samples.csv`, 전체 시험 로그는 같은 step3 폴더에 보존한다.

다음 작업은 4번째 VLM 추론 개선이다. 실물 검사 정확도·노트북·VLM 병행·장시간 운영은 별도 검증이 필요하다.

## 최종 실제 소스 측정

RTX 3090 / Windows / PyTorch 2.9.1+cu128. 물체 수 1/4/8 × 이전/상주 2방식 × 15회 = 90표본을 무작위 순서로 실행했다. 배치 크기 1/2/3/4를 각 방식에서 두 번 준비하고 측정했다. 이전 2단계 완료 상태가 비교 기준이며, 지난 실행의 수치와 직접 비교해 개선율을 계산하지 않는다.

전체 402개 시험 통과(55.482초). 실제 GPU 예제 8개에서 특징/거리 최대 차이 0, 최근접 인덱스 일치. 저장된 합성 기준에서 12개 판정·영역·참조 근거 비교와 OK/NG 경계 동등성을 확인했다. 4,099개 기준을 사용한 청크 경계·동점 검증도 통과했다. 범용 사진과 합성 기준에 대한 결과이며 일반적인 비트 단위 동일성이나 실물 정확도를 보장하지 않는다.
