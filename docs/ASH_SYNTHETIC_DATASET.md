# ASH 합성 학습 데이터 생성

후속 1차 학습을 시작했다. 실제 실행 설정과 불량용 물체 영역 변환은 [합성 학습 안내](ASH_SYNTHETIC_TRAINING.md)를 참고한다. 아래 내용은 원본 데이터 생성 단계의 기록이다.

첫 묶음은 상세 촬영 60조건 × 정상·NG 7종 = 420장, 전체 촬영 120장으로 계획했다. 대상 카메라는 INNOMAKER U20CAM-720P이며 1280×720·명목 수평 화각 102°의 핀홀 근사를 사용한다. 원본은 `datasets/cad-sources/ash-v1`, 생성 결과는 `datasets/ash-synthetic-v2`에 둔다.

## 다양화와 정답

물체 회전은 한 바퀴 전체 범위, 상세 촬영 높이는 가상 장면의 36~60mm, 카메라 중심은 소폭 이동한다. 물체 색상·거칠기, 배경 색상·미세 재질, 조명의 방향·높이·세기와 렌더 시드를 바꾼다. 전체 장면은 위치를 섞고 개수를 1~7개로 바꾸며 빈 작업대도 포함한다. 같은 상세 촬영 조건에서는 정상·NG 7종의 재질·배경·조명·자세를 동일하게 유지한다.

크기는 원본 좌표를 mm로 해석한 가정이다. 실제 물리 치수, 카메라 초점 거리나 로봇 운전 높이를 검증한 값이 아니다. 렌즈 왜곡·초점 흐림·카메라 노이즈·MJPEG 압축·실측 적층무늬는 아직 재현하지 않았다.

물체 정답은 보이는 물체의 상자다. 불량 정답은 동일 자세의 정상 CAD와 NG CAD에서 보이는 기하 깊이 차이로 만든다. NG01 누락은 없어져야 할 물체를 가정하는 것이 아니라 정상에서 있어야 할 구조의 위치를 표시한다. 실제 모델 입력은 RGB이고 깊이 센서를 사용하는 방식이 아니다. 정상 상세사진은 불량 주석 없이 포함한다.

## 생성 품질 검사

다음은 합성 자료를 선별하는 고정 기준이며 실제 제품 판정 임계값이 아니다.

- 화면 가장자리 여유 4픽셀, 물체 상자 한 변 최소 30픽셀.
- 다른 물체에 가려진 면적 비율 최대 0.5%.
- 보이는 불량 기하 영역 최소 80픽셀, 불량 상자 한 변 최소 5픽셀.
- 불량 영역에서 정상/NG RGB의 채널 평균 차이 평균 1.5 이상, 90백분위 4 이상(0~255 기준).

이 검사로 실제 사람이나 AI가 불량을 구분할 수 있음을 보장하지 않는다. 특히 RGB 비교에는 렌더 노이즈나 간접 조명 변화도 포함될 수 있어 이미지 검토와 실물 평가가 별도로 필요하다.

상세 조건의 NG 한 종류라도 기준을 통과하지 못하면 해당 조건의 정상·NG 7장을 함께 제외한다. 클래스별 촬영 조건과 수량이 달라지는 것을 막기 위한 방식이다. 전체 장면은 장면 단위로 제외한다. 제외된 원본을 자동 삭제하지 않으며 `quality/`와 내보내기 보고서에 사유를 남긴다.

## 분할의 의미

상세 조건은 학습 42개 / 검증 9개 / 시험 9개, 전체 장면은 84개 / 18개 / 18개다. 정상·NG의 같은 촬영 조건 묶음은 분할을 넘지 않는다. 코드가 선언한 그룹 분리와 실제 픽셀 중복을 검사한다.

**세 분할 모두 동일한 CAD 7종을 공유한다.** 따라서 결과는 알려진 형상에 대한 새로운 합성 촬영 조건 평가다. 독립 실물이나 처음 보는 불량 형상에 대한 평가라고 주장하지 않는다. `cad_lineage`에 원본 해시를 유지한다. 기존 학습 형식의 `specimen_ids`에는 명시적으로 합성 장면 인스턴스 ID를 쓰며 실물 표본 ID로 해석하지 않도록 메타데이터에 기록한다.

## 저장과 재개

- `plan.json`: 난수 시드, 조건, 분할, CAD 계보가 고정된 생성 계획.
- `contract.json`: 생성 코드·계획·기하의 해시와 렌더 설정.
- `raw/`, `receipts/`: 이미지와 생성 영수증. 재개 시 완료 이미지의 해시를 검사하고 건너뛴다.
- `quality/`, `masks/`: 이미지별 검사 결과와 불량 마스크. 검사 코드·기준 변경 시 과거 결과를 그대로 재사용하지 않는다.
- `training/overview-objects`: 전체 위치 검출용 COCO 학습 자료.
- `training/detail-objects`: 상세 물체 검출용 COCO 학습 자료.
- `training/detail-defects`: 상세 불량 검출용 COCO 학습 자료.
- `training/export-report.json`: 최종 채택 수량, 제외 사유, 분할별 주석 수와 데이터 해시.

생성 도중 중단되면 같은 계획으로 렌더를 다시 실행할 수 있다. 생성 코드나 원본을 변경한 경우에는 새 출력 폴더를 사용한다. 내보내기는 임시 `training.pending`에서 기존 학습 데이터 검증을 통과한 뒤 `training`으로 전환한다. 실패한 임시 결과는 완료 데이터로 취급하지 않는다.

```powershell
& ./.venv/Scripts/python.exe scripts/build_ash_dataset.py prepare --root datasets/ash-synthetic-v3
& ./.venv/Scripts/python.exe scripts/build_ash_dataset.py render --root datasets/ash-synthetic-v3
& ./.venv/Scripts/python.exe scripts/build_ash_dataset.py export --root datasets/ash-synthetic-v3
```

이 단계는 **학습 데이터 준비**다. 학습 실행·가중치 교체·실제 U20CAM 연결·로봇 동작은 수행하지 않는다. 생성한 데이터의 최종 수량과 확인 그림은 해당 데이터 폴더의 보고서를 참고한다.

학습 설정은 `configs/training/ash-synthetic-v2-{overview-objects,detail-objects,detail-defects}.json` 세 파일이다. 기존 RF-DETR Small 초기 가중치와 합성 자료 표시를 사용한다. 30 epoch를 최초 실행 설정으로 두었으며 실제 수렴 결과에 따라 다음 학습 단계에서 조정한다. 파일 준비만으로 학습을 시작하지 않는다. 기존 학습 보고서는 합성 실행을 보수적으로 시험 결과로 표시하므로 이를 실물 품질 승인으로 취급하면 안 된다.
