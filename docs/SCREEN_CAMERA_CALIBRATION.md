# 화면 체크보드 재보정

촬영 설정 · 학습데이터 수집 → 촬영 설정 → 카메라 재보정 · 체크보드.

1. 실제 사용 초점을 맞춰 고정하고 프로필 이름/초점 메모를 입력한다.
2. 평면 모니터를 사용하며 표시 칸의 실제 가로·세로가 같은지 확인한다. 모니터 인치수와 칸의 mm 치수는 렌즈 왜곡 추정에 필수가 아니며, 이 기능으로 로봇 mm 좌표를 구하지 않는다.
3. 모니터가 하나면 `5초 후 수집`: 패턴이 나타난 뒤 카메라 구도를 잡으면 5초 후 촬영하고 결과로 돌아온다. 별도 모니터는 패턴 창을 옮겨 두고 `현재 구도 수집`을 사용할 수 있다.
4. 체크보드 전체와 흰 테두리를 포함해 18장 이상 수집한다. 중앙뿐 아니라 상하좌우, 거리와 기울기를 바꾼다. 초점은 바꾸지 않는다.
5. 계산·검증 → 원본/보정 미리보기 → 저장한 보정값 적용.

원본만 사용한다. 계산에 2/3, 검증에 1/3 구도를 사용한다. 계산 RMS 1px 이하, 검증 평균 1px 이하·최대 2px 이하, 추정 자세 변화 10도 이상을 UI 적용 기준으로 사용한다. 이는 제품 계측 정확도 인증이 아니다. 모니터 평면성·표시 비율·초점 안정성은 사용자가 확인해야 한다.

프로필은 artifacts/camera-calibration/screen-* 에 원본 사진·코너·K/D·검증 결과와 함께 보존된다. 적용 시 이전 acquisition.json과 장비 설정을 백업하고 카메라를 재연결한다. 카메라 식별자와 해상도 불일치는 차단한다. ROI 승인과 기존 고정 좌표 보정을 무효화하며 기존 로봇 보정의 좌표/획득 버전 가드는 유지한다. 다른 초점에서 촬영한 과거 학습 영상에 새 보정값을 소급 적용하지 않는다. 모델 입력 변화도 별도로 확인해야 한다.

실제 장비로 촬영/적용 검증은 아직 하지 않았다. 합성 투영 복원·체크보드 검출·적용/백업·좌표 가드·기존 촬영 설정 회귀 테스트를 실행했다.
