# 수동 도착 검사: 풀뷰로 전체 검사

1. `① 풀뷰 도착 · 촬영`으로 사진을 저장하고 물체 위치를 찾습니다.
2. `③ 풀뷰로 전체 검사`를 누르면 저장한 사진의 모든 검출 영역에 불량 모델을 적용합니다.
3. 왼쪽 물체 번호를 선택하면 오른쪽에 해당 물체를 잘라낸 사진과 결과가 표시됩니다.
4. 필요하면 카메라를 물체 위로 옮겨 기존 `② 상세검사`로 같은 물체를 다시 검사합니다.

표에 `풀뷰` 또는 `상세`를 표시합니다. 마지막으로 수행한 방식의 결과가 화면에 표시되며,
이전 검사 사진과 결과 파일은 회차 폴더에 유지됩니다. 전체 검사 재실행은 모든 물체의 표시를 갱신합니다.

새 버튼은 재촬영이나 물체 재검출 없이 최초 풀뷰의 물체 번호·검출 영역을 재사용합니다.
보정된 저장 이미지에 왜곡보정을 다시 적용하지 않습니다. 모델 묶음·원본 픽셀·회차가 바뀌면
기존 영역을 재사용하지 못하도록 검증합니다. 카메라나 로봇을 움직이지 않습니다.

불량 검사는 물체별로 순차 처리됩니다. VLM을 켜면 각 물체의 설명을 비동기로 요청하며,
한 사진에 여러 물체가 있어도 스냅샷 해시와 개별 물체 ID로 연결합니다.
기본 판정은 기존 미검증 판정 정책에 따라 보류이며 VLM이 판정을 바꾸지 않습니다.

풀뷰 확대는 실제 근접 촬영처럼 세부 픽셀을 늘려주지 않습니다. 작은 불량의 검출 성능은
실물에서 기존 상세 촬영 결과와 비교한 뒤 운영 방식을 결정해야 합니다.
