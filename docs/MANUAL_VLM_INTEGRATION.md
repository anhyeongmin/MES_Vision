## 사용

프로그램을 다시 실행하고 수동 도착 검사를 연다. 풀뷰 촬영 후 물체를 선택하고 해당 물체의 상세사진을 촬영한다. `VLM 보조 설명`을 켜면 NG04 접합부 또는 NG05 구멍 검출 후보가 있는, 물체 하나와 연결된 상세사진을 자동 분석한다. 이미 촬영했다면 `선택 사진 분석 / 재시도`를 사용할 수 있다.

기본 검사 근거는 위쪽에 그대로 표시되고, 아래쪽 별도 영역에 분석 대기/분석 중/설명/확인 불가가 표시된다. VLM은 기본 판정을 변경하지 않는다. 지원하지 않는 불량 유형은 설명하지 않는다. 메인 창과 VLM ON/OFF 및 큐를 공유하며, 수동 검사를 독립 실행하면 필요한 순간 자체 작업자를 시작한다.

설명은 snapshot digest, object_id, job_id로 연결한다. 다른 물체 선택, 재촬영, 새 회차에서 이전 설명이 새 결과에 붙지 않도록 처리했다. OFF나 설명 오류가 카메라의 대기 중 촬영을 취소하지 않는다. session.json에 작업 연결 정보를 보존하고 실제 설명은 VLM 큐에 저장한다.

## GPU 및 종료

수동 검사 모델은 로드 및 추론 동안만 GPU 우선권을 잡는다. 로드 후 여유 메모리 12 GiB 이상/전체 20 GiB 이상이면 상주 상태에서 VLM을 허용한다. 부족하면 VLM 요청 시 유휴 수동 모델을 해제하며 다음 검사에서 다시 로드한다. 기존 다른 ResidentPhotos 호출의 기본 동작은 유지한다.

X 종료는 한 번만 정리를 시작하고 완료 후 닫기 이벤트를 허용한다. 모델 프로세스 종료 핸들러를 Qt QDialog.finished 신호와 다른 이름으로 연결했다. 수동 창에서 소유한 VLM 작업자와 카메라만 종료하며, 메인 창의 카메라/작업자는 유지한다.
