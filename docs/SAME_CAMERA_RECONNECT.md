# 같은 카메라를 다른 PC/USB 경로에서 다시 연결

`Lens calibration belongs to another camera`는 저장된 보정의 장치 식별값과 선택한 카메라의 값이 다르다는 뜻입니다. UVC 식별값은 장치 경로 기반이므로 같은 물리적 카메라도 PC에 따라 달라질 수 있습니다.

1. 프로그램을 닫고 프로젝트 폴더에서 `git pull --ff-only`를 실행합니다.
2. `MES Vision.cmd`를 실행하고 장비 설정을 엽니다.
3. U20CAM과 기존 보정의 해상도(현재 1280×720), MJPEG/30fps를 선택합니다.
4. 아래쪽 **동일 카메라 · 기존 렌즈 보정 연결**을 누릅니다.
5. 동일한 실제 카메라이며 렌즈·초점을 변경하지 않은 경우에만 **Yes/예**를 선택합니다.
6. **저장**을 누릅니다. 취소하면 연결 설정을 쓰지 않습니다.

패키지에 포함된 보정 JSON과 그 해시는 그대로 보존됩니다. 새 장치 연결은 `artifacts/operation/camera-acquisition.json`에 따로 저장되며, 변경 전 장비/보정 설정과 확인 기록은 같은 폴더의 `camera-binding-history/`에 남습니다. 이후 재보정하면 활성 로컬 설정이 갱신됩니다.

작업 영역과 로봇 좌표의 기존 검증은 초기화됩니다. 다른 장치에 대한 일치 검사, 해상도 검사 및 보정 파일 해시 검사는 유지됩니다. 동일 장치 확인은 사용자의 물리적 확인이며 소프트웨어가 카메라 제조번호를 확인한 것은 아닙니다.

모델 재다운로드, Setup 재실행, 재학습은 필요하지 않습니다. 렌즈/초점을 변경했다면 이 기능 대신 재보정해야 합니다.
