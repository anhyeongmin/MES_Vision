# 실물 수집·라벨링 지침

실물 도착 후 사용할 작업 지침이다. 현재 어떤 결함이 D405 상면 사진에서 구별 가능한지, 정상 허용 오차가 얼마인지는 확정하지 않는다.

## 촬영 전에 정할 것

품목 ID와 정상 기준 도면·사진을 준비한다. 검사면이 위를 향하는지, 누락·균열 등 각 결함이 상면에서 실제로 보이는지 먼저 확인한다. 보이지 않거나 해상도가 부족한 결함을 추측해서 라벨링하지 않는다. 깊이 또는 다른 검사가 필요한 항목은 기준 협의 대상으로 남긴다.

정상과 NG01~NG06의 실물마다 영구적인 ID를 붙이고 [실물 목록](../templates/specimen_inventory.csv)에 기록한다. ID 표식 자체가 모델의 정답 단서가 되지 않도록 검사 이미지 밖에서 관리한다. 제작자가 알려준 유형과 이미지에서 관찰한 상태가 다를 수 있으므로 둘을 기록상 구분한다. 같은 실물을 돌려 찍어도 새 실물 ID를 발급하지 않는다.

[촬영 계획](../templates/capture_plan.csv)에 회차 ID, 실물 ID 목록, 분할, 조명·카메라·배경 설정을 기록한다. 현재 알 수 없는 값은 비워 두고, 사용하지 않는 항목은 이유와 함께 N/A로 기록한다. 폴더나 파일 이름에 적었다고 프로그램에 자동 반영되지는 않는다. 가져오기 시 동일 회차 ID, 라벨링 시 동일 실물 ID를 입력한다.

## 학습·검증·시험을 나누는 기준

- 실물 개체를 먼저 나누고, 촬영 회차도 분리한다. 한 회차는 한 분할만 사용한다. 한 사진에 서로 다른 분할의 실물을 함께 놓지 않는다.
- 같은 개체의 회전·재촬영·잘라낸 이미지·증강 결과는 같은 분할에 둔다. 연속 영상의 인접 프레임도 같은 회차로 관리한다.
- 모델 학습과 정상 특징 등록은 train만 사용한다. 모델·임계값 선택은 valid, 확정 후 별도 성능 측정은 test를 사용한다. test 결과를 보고 반복 조정하면 그 자료는 더 이상 독립적인 최종 시험으로 간주하지 않는다.
- 예상 밖 불량과 판독 불확실은 challenge로 보관한다. 그 사진에 함께 등장한 정상·알려진 불량과 해당 회차·연결된 실물의 다른 사진까지 같은 분할로 옮긴다. 먼저 관련 회차를 미지정으로 바꾸고 묶어서 재배정하면 중간 충돌을 해결할 수 있다.
- 미등록 유형 시험을 설계할 때는 해당 유형이 학습·정상 참조·예시 설명에 들어가지 않도록 따로 관리한다. challenge가 생겼다는 이유만으로 이미 학습에 사용한 자료를 독립 시험으로 재사용하지 않는다.
- 유형별 네 개 등 적은 개체로 여러 장을 찍어도 독립적인 실물 수가 늘지는 않는다. 지금 고정 비율이나 충분한 장수를 선언하지 않는다. 별도 개체와 촬영 회차가 부족하면 데모와 일반화 성능 검증의 한계를 기록한다.

## 물체와 불량 표시

물체 위치 모델에는 정상·불량 구분 없이 모든 대상 물체의 전체 외곽 상자를 표시한다. 그림자·옆 물체를 포함하지 않고, 인접 물체가 가리지 않는 사진을 기본으로 한다. 상자는 이미지 원본의 `[왼쪽, 위, 오른쪽, 아래]` 픽셀 좌표이며 오른쪽·아래는 경계값이다. 결함 상자는 해당 물체 상자 안에 둔다.

| 코드 | 관찰 유형 | 표시 기준 |
|---|---|---|
| NG01 | 누락 | 눈으로 확인 가능한 누락의 기대 위치·부분을 기준과 대조. 표시할 영역이 없으면 영역 없이 설명 |
| NG02 | 돌출·버 | 기준 외 추가 재료의 실제 보이는 범위 |
| NG03 | 균열 | 균열 선을 포함하는 범위. 크기를 과장하거나 정상 경계선을 균열로 라벨링하지 않음 |
| NG04 | 변형 | 정상 기준과 비교해 확인한 변형 범위. 전반적인 형상 차이만 있으면 영역 없는 관찰도 허용 |
| NG05 | 구멍 불량 | 막힘·형상·크기 이상이 보이는 위치. 정량적인 구멍 크기 합격 여부는 보정·기준 확정 후 |
| NG06 | 표면 결함 | 찍힘·패임·긁힘 등 확인 가능한 영역. 조명 반사·출력 적층 자국의 정상 허용 범위와 구분 |

한 물체에 여러 결함을 기록할 수 있고 같은 코드도 다른 위치마다 추가한다. 알려진 불량을 표시하면 상태가 ‘알려진 불량’으로 바뀐다. 누락·변형처럼 상자만으로 충분하지 않은 항목은 형상 검사 기준도 후속 단계에서 준비한다. 없는 부품에 임의 상자를 만들어 모델 학습을 강행하지 않는다.

NG 번호는 고정된 의미를 가진다. 새로운 현상을 다음 번호로 자동 발급하지 않는다. 기존 코드에 억지로 맞추지 말고 ‘미등록 불량’과 관찰 메모를 사용한다. 단지 판단이 어려운 경우는 ‘판독 불확실’을 쓴다. 정상 물체에는 불량 라벨이 없어야 하지만, 라벨이 없다는 이유만으로 정상 처리하지 않는다.

영역 없는 불량이나 선택하지 않은 유형이 하나라도 있는 물체는 불량 모델 내보내기에서 전체를 제외한다. 일부 결함만 남겨 잘못된 정상 배경으로 학습하는 것을 방지한다. 물체 위치 데이터에는 검토·분할 조건에 맞으면 사용할 수 있다.

## 검토 시 확인

화면을 확대하여 모든 물체가 표시됐는지, 다른 사진의 동일 실물 ID가 유지됐는지, 복수 결함이 빠지지 않았는지 확인한다. 관찰 상태와 라벨을 대조하고, 경계가 애매한 사례는 제작자·검사 기준 담당자와 확인해 메모한다. 흐림·가림·노출 실패 사진은 정상으로 바꾸지 말고 사유를 적어 제외한다. 가능하면 다른 검토자가 표본과 경계 사례를 다시 확인하고 의견 차이를 정리한다.

검토 완료와 분할 지정 후 내보내기 보고서의 제외 항목을 확인한다. 단순히 내보내기가 성공했다는 이유로 제외된 유형의 검사까지 준비됐다고 판단하지 않는다. 최종 정상/불량/보류 결정은 사람 라벨 상태와 별개의 10 단계 판정 로직에서 다룬다.
