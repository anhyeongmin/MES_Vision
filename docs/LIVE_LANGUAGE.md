# 언어 즉시 적용

환경설정 → 표시 언어 → 저장을 누르면 한국어, 영어, 중국어 간체, 태국어가 재실행 없이 적용된다. 취소하면 저장된 언어와 현재 화면을 변경하지 않는다.

운영 화면의 다섯 페이지, 메뉴, 표 제목과 상태, 검사 이유, 설정 팝업, 열린 이미지 검토 창의 안내 문구를 갱신한다. 현재 페이지, 검색 조건, 선택한 물체, 이미지 확대·이동, 품목명과 입력값은 유지한다. 카메라·검사 엔진·로봇·VLM 작업을 다시 생성하거나 중단하는 명령을 보내지 않는다.

품목명·메모·경로·모델 관찰 내용은 자동 번역하지 않는다. 저장된 검사 원본이나 이전 로그도 수정하지 않는다. 기본 파일 선택창은 운영체제 언어를 따를 수 있다. 별도 프로세스로 이미 열린 학습 도구는 해당 프로세스에서 선택한 언어를 사용한다.

## 구현

- `i18n.DisplayText`는 번역 원문과 사용자 값을 구분하여 보존하는 문자열이다. `tr`, `trf`, `text_join`으로 조합한 화면 문구만 재번역한다. 저장·로그 문자열을 역검색해서 치환하지 않는다.
- `qt_i18n.ui_text`는 Qt 표시 호출에 번역 정보를 연결한다. `bound_text`로 다른 표시 영역에 문구를 복사할 때도 원문을 유지한다. 신규 화면 문구는 같은 방식을 사용한다.
- 번역 변경 시 기존 위젯을 갱신한다. 입력·선택 신호를 차단하고 현재 값과 연결 정보가 일치하는 항목만 바꾼다. 이후 사용자 편집이나 다른 쓰기로 변경한 문자열은 덮어쓰지 않는다.
- 표·목록 항목의 번역 정보는 별도 Qt 데이터 역할에 보관한다. Python 래퍼가 다시 만들어져도 원문이 유지되며, 삭제된 행을 별도로 누적 보존하지 않는다.
- Qt 기본 버튼 번역과 시스템 글꼴도 갱신한다. 설치된 글꼴은 한 번만 등록한다.
- 언어 갱신 자체는 검사 원본·데이터베이스를 다시 읽거나 모델을 실행하지 않는다. 기존 비동기 작업은 계속 동작한다.

## 검증

- 전체 자동 검사 527개 통과. 즉시 언어 적용 검사는 12개 포함한다.
- 같은 프로그램 인스턴스에서 영어 → 중국어 → 태국어 → 한국어 왕복, 실제 환경설정 저장·취소 흐름, 기본 버튼과 팝업 입력값 보존을 검사했다.
- 장치·엔진·VLM 참조와 검사 상태, 선택 기록, 메뉴·표 항목, 편집 중인 장치 식별자, 이미지와 확대 상태 유지 및 불필요한 조회가 없는지 확인했다.
- VLM의 기본 검사 근거와 화면 안내만 번역하고 생성된 관찰 문장을 보존하는지 검사했다.
- Windows Qt offscreen에서 4개 언어 × 5개 페이지와 환경설정 팝업을 캡처했다. 빈 운영 자료에서 언어 적용과 화면 갱신은 약 55–84ms였다. 실제 장비 가동 중 지연 보장은 아니며 Ubuntu·실물 장비 운전 검증은 별도로 진행한다.
