# VLM OK~NG06 연결

2026-09-16. 사용자의 전체 종류 지원 요청에 따라 기존 2B 모델을 추가 학습하고 연결했다. 기존 검사 판정과 좌표계 가드는 유지했다. UI_HANDOFF §0 담당 범위 내의 모델 경로 및 명시적으로 요청된 수동 검사 설명 연결만 수정했다. 기존 테스트는 변경하지 않았다.

## 운영

프로그램을 재실행하고 수동 검사에서 VLM 보조 설명을 켠다. 상세사진이 물체 하나에 연결되면 OK(불량 후보 없음)~NG06 모두 요청할 수 있다. 이전 사진은 선택 사진 분석/재시도를 사용한다.

| 입력 | VLM 관찰 범위 |
|---|---|
| 불량 후보 없음 / OK | 전체 물체의 원통 개수·배치. 정상 확정이 아님 |
| NG01 | 전체 물체의 원통 개수·누락 |
| NG02 | 검출 영역의 사각 돌출물 |
| NG03 | 검출 영역의 선 모양 균열 |
| NG04 | 기존 어댑터로 접합부 틈 관찰 |
| NG05 | 기존 어댑터로 원통 구멍 관찰 |
| NG06 | 검출 영역의 원형 표면 흔적. 깊이를 단정하지 않음 |

NG04/NG05에는 기존 `models/vlm-region-abstain-v1` 가중치를 그대로 사용한다. 나머지는 `models/vlm-all-classes-training-20260916-013722`를 사용한다. GPU에는 기본 2B 모델 하나를 올리고 작은 LoRA 두 개를 질문별로 선택한다. 모든 답변은 보조 정보이며 기본 판정을 변경하지 않는다.

검출 후보는 기존처럼 최대 3개 영역을 순차 설명한다. NG01 중복 검출은 같은 전체사진 질문을 한 번만 실행한다. 후보가 없는 경우의 전체 관찰은 OK 판정의 근거를 완전히 검증하는 기능이 아니다. 미지원 코드를 정상으로 바꾸지 않는다. 이전 요청과 새 프로토콜의 결과가 재사용되지 않도록 큐 요청 버전을 갱신했다.

## 학습과 검증

- 기존 실사진 자료와 기존 지역 설명 예제를 사용했다. 학습 예제 289개, 별도 비교 예제는 이전 세션/이전 실험에서 사용한 사진으로 만든 42개. 독립 성능 시험은 아니다.
- 균형 샘플링으로 회차당 84예제, 6회 추가 학습. 회전 0/90/180/270도, 밝기 0.9~1.1 증강, assistant 답변 토큰만 손실 계산, 기존 어댑터에서 시작.
- 453개 자료의 해시와 399개 새 입력의 원본 크롭 픽셀 일치를 확인했다. 이중 보정을 하지 않았으며 동일 사진/질문에 모순된 설명 정답이 없는지 확인했다.
- NG02/NG03/NG06 양성 영역 33장은 접촉시트로 시각 확인했다. 정답은 기존 사용자 원 표시와 assistant 초안에 기반하므로 독립적인 사람 정답 전체 검토는 아니다.
- 42개 답변 모두 JSON 형식 유효. 구체적인 질문의 NG01, NG02, NG03, NG06 사례는 참고 설명과 맞았지만, 포괄적인 전체 설명 질문에는 오류와 불확실 응답이 있었다. 따라서 운영의 OK 질문도 학습에서 확인된 원통 개수 관찰 질문으로 제한했다.
- 현재 DETR을 오래된 실사진 7종에 실행하고 실제 검출 상자로 VLM을 호출했다. 오탐 후보가 있는 사진 및 일부 NG02/NG03/NG05 영역에서는 불확실/미관찰 답변이 나왔다. 이를 정답 성공으로 집계하지 않았다. `runtime-check-v2`의 passed는 실행/스키마/연결 통과를 뜻하며 정확도 통과를 뜻하지 않는다.
- 수동 UI의 실제 VLM 작업자를 이용한 7종 요청, 선택 결과 표시, 객체 연결, 기본 판정 불변, OFF, X 종료 확인 완료. OK 사례는 실제 불량 후보가 없던 이전 스냅샷을 사용했다.
- 관련 기존/신규 테스트 66개 통과.

## 결과 파일

- `artifacts/vlm-all-classes-v1/training-20260916-013722/report.html`: 학습 전후 개별 응답.
- 같은 폴더 `run.json`, `before.json`, `after.json`, `candidate-backend.json`: 학습/후보 기록.
- `artifacts/vlm-all-classes-v1/runtime-check-v2/results.json`: 현재 DETR → VLM 실제 실행.
- `artifacts/vlm-all-classes-v1/manual-check-13803b40/results.json`: 수동 UI 7종 결과.
- `artifacts/vlm-all-classes-v1/final-tests.log`: 66개 테스트 결과.
- `artifacts/vlm-all-classes-v1/before/`: 기존 코드/설정 백업. 기존 모델도 보존했다.

초기 실행에는 모델 로딩 시간이 별도로 필요하다. 영역 개수가 늘면 지연도 증가하며, 모든 물체가 1~2초 내 완료된다고 보장하지 않는다. 실제 카메라 새 촬영과 로봇 시험은 수행하지 않았다.
