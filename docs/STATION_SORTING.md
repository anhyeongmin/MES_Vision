# 전체·상세 검사 후 분류 이송

2026-09-09. 로봇 장착 카메라의 상세 검사 결과와 전체사진의 집기 좌표를 연결했다. 실제 장비 연결·이동·학습이나 현장 성능 평가는 하지 않았으며, 아래 연결은 모의 장치와 주입한 영상으로 검증한 소프트웨어다.

## 사용하는 방법

`검사 운영`의 **검사 후 자동 분류**를 켜고 검사 시작을 누른다. 선택하지 않으면 상세 검사 완료까지 수행한다. 프로그램을 새로 실행하면 자동 분류는 꺼져 있으며, 검사 도중 선택을 바꿀 수 없다. 한국어·영어·중국어·태국어가 즉시 적용된다.

모든 물체의 상세 검사가 끝난 뒤 OK·NG만 순서대로 각 등록 목적지로 옮긴다. 보류는 자동으로 옮기지 않는다. VLM OFF이거나 설명이 대기 중이어도 검증된 기본 판정으로 진행한다. 전체사진은 해당 회차의 저장된 장면을 유지하고, 이송 후 실시간 작업대 모습은 별도 카메라 영상에서 확인한다.

물체 목록은 기본 판정과 이송 상태를 구분한다. 진행 상태에 `분류 이송 중`, `이송 완료`, `이송 확인 필요`를 표시한다. 중단·오류·재시작 때 진행 중이던 이송을 완료로 처리하지 않는다. 앞서 완료된 이송과 기본 OK/NG 판정은 유지한다.

## 이송 전에 확인하는 자료

- 현재 회차가 발행한 요청인지, 모든 상세 검사가 끝났는지, 선택 물체가 OK/NG인지 확인한다. 취소된 회차·무효 좌표·중복 요청은 사용하지 않는다.
- 저장된 전체 원본과 상세 원본의 픽셀·파일 식별값, 카메라 세션, 회차·물체 ID 연결을 확인한다. 전체사진의 검출 영역을 검증된 보정에 다시 넣어 저장된 촬영·집기 좌표와 비교한다.
- 상세 판정 정책을 저장된 검사 근거에 다시 적용한다. 결과와 정책 식별값이 원래 판정과 일치해야 한다. VLM 문장으로 분류를 결정하지 않는다.
- 로봇 운전 프로필, 촬영 설정 버전, 보정, 연결 식별값, 현재 위치, 빈 집기 상태를 확인한다. 전체사진 좌표 유효시간은 원래 전체사진 촬영 시점부터 계산하며 상세사진이나 VLM 결과 도착으로 연장하지 않는다.

큰 영상과 판정 자료의 검증은 별도 읽기 작업으로 수행한다. 이 작업이 지연돼도 로봇 장치 스레드는 상태 확인과 정지 요청을 처리한다. 취소 후 늦게 끝난 검증으로 명령을 시작하지 않는다. 한 번에 한 검증만 허용하며, 취소된 읽기가 끝나기 전에는 새 로봇 작업을 허용하지 않는다.

## 이동과 확인

현재 근접 촬영 위치에서 수직 상승 → 집기점 위로 이동 → 집기 높이 하강 → 집기 동작 → 독립 입력으로 집기 확인 → 상승 → 목적지 위로 이동 → 하강 → 놓기 → 빈 집기 입력 확인 → 상승 순서다. 각 이동은 완료 응답과 측정 위치를 확인한다. 이송 중 집기 신호가 사라지면 중단한다.

목적지 도달, 놓기 후 빈 집기 입력, 마지막 상승까지 확인하고 로봇 기록을 저장해야 `이송 완료`가 된다. 이것이 별도 카메라로 목적지에 물체가 놓인 상태까지 검사한다는 의미는 아니다. 현재 독립 확인 수단은 등록된 디지털 입력이다.

물체별 명령과 완료 근거는 `robot/robot.sqlite3`의 `station_sorts` 및 기존 로봇 이벤트에 기록한다. 동일 회차·물체의 집기는 한 번만 예약하며, 결과가 불확실해도 자동 재전송하지 않는다. 시퀀스는 단순한 성공값만 받아 완료 처리하지 않고 저장된 로봇 완료 기록과 대조한다.

## 설치 후 검증할 조건

좌표 유효시간에는 전체사진 이후 모든 상세 검사와 앞선 물체의 이송 시간이 포함된다. 등록된 시간이 지나면 새 회차가 필요하다. 각 분류 요청은 촬영 설정의 단계 제한 시간, 각 명령은 로봇 프로필의 명령 제한 시간을 따른다. 임의로 시간을 늘리지 말고 실제 작업 시간과 장면 정지 조건을 측정해 등록해야 한다.

전체 경로에서 카메라·그리퍼·케이블·물체 간 간섭이 없는지, 앞선 집기가 남은 물체를 움직이지 않는지, 같은 목적지에 연속해서 놓을 수 있는 구조인지 확인해야 한다. 소프트웨어의 좌표 범위 검사가 충돌 회피나 목적지 적재량 감지를 계산하지는 않는다. 물체가 움직이거나 이송 결과가 불확실하면 현장을 확인하고 새 전체사진으로 시작한다.

이번 테스트는 실제 Magician 동작, 정지 지연, 독립 센서 신뢰도, 목적지 적재, 실물 정확도·처리 시간을 검증하지 않았다. 설치 배포는 현장 검증 후 진행한다.

## 소프트웨어 검증

신규 검사는 전체·상세 증거 연결, OK/NG 두 물체 이송과 보류 제외, UI 자동 분류 선택, 원본 변조, 좌표 만료, 이동 오차, 명령 시간 초과, 물체 놓침, 잘못된 확인 신호, 기록 실패, 중복 요청, 취소·재시작, 실제 장치 스레드의 모의 동작과 검증 지연 중 정지를 포함한다. 테스트용 운전 파일은 임시 폴더에만 기록하도록 경로를 강제한다.

최종 전체 자동 검사 **623개 통과(147.403초)**. 신규 분류 검사 18개가 포함된다. 네 언어 × 두 화면 크기로 8장을 렌더링하고 한국어·태국어 배치를 직접 확인했다. 최종 로그와 네 언어 화면 확인 자료는 `artifacts/station-sort/`에 보존한다. 화면의 회색 배경은 주입한 검사용 이미지이며 실물 검사 결과가 아니다.

후속 작업으로 새 회차의 기존 이력 검색·내보내기·수동 검토·보존 정책을 통합했다. [STATION_HISTORY.md](STATION_HISTORY.md)를 참고한다. 실제 장비가 준비되면 촬영·보정·전체 경로·모델·센서·처리 시간을 검증한다.
