# VLM 실행 방향 — 사용자 확정

결정일: 2026-09-05. 사용자 결정 기록. 09 구현 내용과 검증 범위는 [VLM.md](VLM.md)를 따른다.

사용자 확정: 기본 검사 결과와 NG/보류 근거는 VLM 응답 전에도 확인할 수 있게 한다. 원본·물체 이미지와 검사 결과를 저장하고, VLM은 저장된 자료를 후속 분석하여 결과창에 설명을 추가한다.

- 기본 검사 근거에는 검사 항목, 알려진 불량 유형, 근거 위치, 해당하는 경우 측정값과 적용 기준을 표시한다. 이상 차이만 확인한 경우 구체적인 결함 이름을 추측하지 않는다.
- 기본 검사 결과와 VLM 추가 분석은 별도 항목으로 유지한다. VLM 응답 대기가 기본 검사 표시와 일반 분류의 필수 대기 조건이 되지 않도록 설계한다. 기본 검사에서 보류한 물체는 보류를 유지한다.
- 이미지와 결과가 저장된 후 검사 ID·물체 ID·모델/기준 버전으로 분석 요청을 연결한다. 늦게 도착한 응답을 다른 프레임이나 물체에 붙이지 않는다.
- 대기/분석 중/완료/실패 상태를 표시한다. 작업 수와 동시 실행 수를 제한하고 기본 검사 응답 시간에 미치는 GPU 간섭을 측정한다. 적체 시 불량·보류 분석을 우선하며 생략·지연 상태를 숨기지 않는다.
- 재시작 시 미완료 요청을 식별·재개할 수 있도록 작업 상태 저장과 중복 완료 방지를 구현한다. 09에 필요한 최소 작업 저장을 만들고 14에서 검사 이력 전체와 연결한다.
- VLM 후속 의견은 과거 판정·로봇 동작을 소급 변경하지 않는다. 새로운 의심은 추가 검토 의견/알림으로 기록한다. VLM 설명만으로 확정 불량을 해제하지 않는다.
- 전수 VLM 확인을 출하 전 필수 조건으로 요구하는 품목은 별도 운전 정책이 필요하며, 후속 분석 모드를 그러한 검사로 주장하지 않는다.

사용자 확정: 먼저 PySide6 제품을 완성하고 그 후 WinForms 버전을 추가한다. 공통 Python 검사 엔진을 재사용하며, 두 UI 모두 기본 검사와 VLM 후속 분석의 작업 경계를 유지한다.

사용자 추가 요청: UI에서 VLM 사용 여부를 ON/OFF 버튼으로 선택한다. 기본 OFF로 시작하고 설정을 저장한다. OFF 시 신규 분석 생략·대기 취소·진행 중 모델 종료를 수행하며 기본 검사 근거와 완료된 VLM 이력을 유지한다. 다시 ON으로 바꿔도 취소·생략 작업은 자동 재시도하지 않는다.
