# 수동 검사의 VLM 미리 로드

2026-09-16. 기존 `모델 미리 로드` 버튼에 선택된 VLM 준비를 연결했다. VLM OFF이면 비전 모델만 로드한다. ON이면 비전 모델을 먼저 준비한 뒤 사진 없이 VLM을 로드한다. 비전 모델이 이미 준비된 상태에서 VLM을 켜도 VLM 준비를 요청한다.

수동 검사 창에 VLM 모델의 미로드/대기/로드 중/준비 완료/실패 상태를 별도로 표시한다. `모델 해제`는 비전 모델과 VLM 유지 요청을 해제한다. 요청한 창의 종료, 취소, OFF에서도 유지 요청을 해제한다. 메인 창의 공용 작업자는 종료하지 않는다.

미리 로드는 검사 작업이나 가짜 사진/판정을 만들지 않는다. 명시적인 미리 로드 요청이 있는 동안은 기존 30초 유휴 만료를 적용하지 않는다. CUDA를 쓰는 기존 모델 자식 프로세스를 그대로 사용하며, 로드 실패는 표시하고 무한 반복 재시도하지 않는다.

활성 resident lease가 충분한 메모리를 확인해 `allow_vlm=true`를 명시한 경우에만, 유휴 VLM 가중치를 유지한 채 GPU 실행 잠금을 비전 검사에 양보한다. 메모리 공유가 승인되지 않은 검사, 메모리 부족, OFF, 종료에서는 기존 해제 경로를 유지한다. 실행 중인 VLM 추론을 정지해야 하는 경우에는 기존 취소/재대기 경로를 사용한다. 메모리 상태 응답이 오가는 순간의 양보도 응답을 먼저 회수하여 다음 추론 응답과 섞이지 않도록 했다.

검증 기록:

- `artifacts/vlm-preload-v1/run-816b7ab5/report.json`: RTX 3090에서 사진 없이 DETR 3개와 선택된 VLM 로드, 실제 저장 사진 DETR 검사 전후 VLM PID 동일, 다음 VLM 작업 `model_reused=true`, `model_load_seconds=0`, 모델 해제와 X 종료 통과.
- 해당 첫 준비는 약 26초. 초기 로드 시간을 검사 전에 지불하는 기능이며 추론 시간이 0초가 되는 것은 아니다.
- 로봇/실카메라 조작 없음. 기존 require 가드 및 기존 테스트 변경 없음.
- 기존 파일 백업은 `artifacts/vlm-preload-v1/before/`.

사용 중인 프로그램은 재실행해야 변경이 적용된다.
