# 전체·상세 검사: 사전 점검과 현장 검증

현행 흐름은 전체 촬영 → 위치 검출 → 개별 근접 촬영·판정 → 선택적 분류 → 이력 보존이다. 아래 순서는 새 로봇 장착 카메라 방식 기준이다. 설치 배포는 현장·노트북 검증 이후 진행한다.

## 장비 없이 지금 실행할 점검

프로젝트 폴더에서 PowerShell로 실행한다.

```powershell
& ./.venv/Scripts/python.exe ./scripts/check_station.py --run-tests
```

`artifacts/station-check/<실행별 폴더>/report.md`가 사람이 읽는 결과이며, 같은 폴더에 JSON 결과·시험별 로그·소스 파일 SHA256 목록을 남긴다. `--runtime`으로 실제 사용하는 운영 폴더를 지정한다. 기본은 `artifacts/operation`이다. `--output`은 보고서 저장 위치를 지정한다. `--run-tests`를 생략하면 등록 자료만 확인한다.

보고서는 현재 등록된 모든 품목의 최신 버전과 최신 장비 설정을 읽는다. 화면에 적용한 품목을 추정하지 않으며, 비활성 품목이나 다른 품목 보정도 확인 필요로 나올 수 있다. 상세 검사 기본 조건·등록 모델 파일, 전체·상세 촬영 설정, 촬영 보정 파일·설치 문맥, 로봇 운전 파일과 보정 연결을 확인한다. 전체 모델을 메모리에 적재하거나 장치를 연결하지 않는다. 프로그램의 실제 검사 시작 검증을 대체하지 않으며 모든 자산·물리 조건을 검증하는 도구도 아니다.

운영 DB는 읽기 전용 연결과 한 읽기 트랜잭션으로 확인한다. 데이터베이스 갱신·복구, 모델 다운로드·학습, 자동 보정이나 운전 설정 저장을 수행하지 않는다. SQLite가 읽기에 필요한 WAL/SHM 보조 파일을 관리할 수 있지만 운영 기록을 변경하는 SQL은 실행하지 않는다. 외부 등록 파일은 점검 순간의 값이며, 앱에서 설정을 변경한 뒤에는 다시 점검한다.

선택적 자동 시험은 별도 프로세스에서 기존 회차·장치·운영 화면·분류·이력 시험과 이 도구의 시험을 실행한다. 임시 폴더, 주입한 영상과 모의 장치를 사용한다. 시험 0개, 실패, 건너뛴 시험, 예상 실패는 완전 통과로 표시하지 않는다. 시험 제한 시간은 600초다. 실행 중 소스가 바뀌면 통과 근거로 사용할 수 없음을 표시한다.

종료 코드: `0` 등록 검사 통과(실물 승인 아님), `1` 자동 시험 실패 또는 점검 중 소스 변경, `2` 등록 확인 필요. 장비와 실물 학습 자료가 준비되지 않은 현재에는 `2`가 자연스러운 결과다. 등록 검사 통과 및 자동 시험 통과여도 실제 장비 검증은 항상 **미평가**로 남는다.

## 실물이 준비되면 진행할 순서

| 순서 | 수행할 작업 | 남겨야 하는 근거 |
|---|---|---|
| 1 | 마운트·작업대·조명·검사면·카메라 해상도를 고정하고 전체/근접 원본 확보 | 설치 버전, 원본 사진, 각 촬영 자세, 렌즈에서 검사면까지 거리 |
| 2 | 전체영상은 물체 위치를 찾을 만큼, 근접영상은 가장 작은 대상 불량을 구분할 만큼 보이는지 확인 | 정상/각 불량/경계 위치·방향별 원본, 최소 대상 불량 크기 |
| 3 | 실제 정지 뒤 안정 시간과 영상 지연을 측정 | 측정 방법·최악값·반복 기록. 수신 시각을 노출 시각으로 간주하지 않음 |
| 4 | 같은 전체사진 기준점에서 촬영점용·집기점용 좌표 보정 및 독립 검증 | 각 보정 6개 이상 계산점·4개 이상 독립 검증점, 오차·검증 영역, 검사면 높이 |
| 5 | 전체·근접·집기·목적지 경로와 독립 입력을 점검 | 카메라·케이블·집게 여유, 이동/정지 기록, 물체 있음/없음 입력, 연속 적재 |
| 6 | 전체 위치 검출과 상세 불량 모델을 실제 촬영 자료로 학습·검증 | 학습/검증/최종평가 분리, 모델·정책 버전, 정상 기준 자료, 품목별 성능 |
| 7 | 자동 분류 OFF에서 여러 물체의 전체→상세 연결·기본 판정·보류를 확인 | 회차 원본과 결과, 누락·중복·물체 연결 오류, 클릭한 물체와 상세사진 일치 |
| 8 | 자동 분류 ON에서 전체 상세 검사 완료 뒤 OK/NG 이송 확인 | 보류 제외, 집기/놓기 확인, 좌표 유효시간, 앞선 이송 뒤 남은 물체 정지 |
| 9 | VLM OFF/ON, 중단·통신 끊김·앱 재시작·원본 저장 오류를 확인 | VLM을 기다리지 않는 기본 판정, 늦은 응답 배제, 과거 좌표 자동 재개 없음 |
| 10 | 물체 수별·장시간 운전과 RTX5070 노트북 검증 | 첫 회차/준비 후 회차 시간, 상위 지연, GPU/메모리, 누락·오탐·보류율 |

자동 분류 OFF라도 근접 촬영을 위해 로봇이 움직인다. 검증된 설치 조건으로 직접 시작해야 한다. 기존 `촬영·집기 보정 만들기`는 측정 완료된 두 파일을 묶는 기능이며 자동 측정 도구가 아니다.

불량 통과율·정상 오탐률·보류율, 허용 좌표 오차, 최대 처리 시간의 합격 기준은 실제 대상 불량과 공정 요구에 맞춰 최종평가 전에 정한다. 임의의 수치를 프로그램 기본 합격값으로 넣지 않는다. 연속 프레임이나 같은 실물의 거의 같은 사진을 학습·평가 양쪽에 나눠 넣지 않는다. 미학습 불량은 별도 평가하며 어떤 모델도 모든 미지의 불량 검출을 보장하지 않는다.

최종 기록은 날짜·담당자·품목/장비/모델/보정 버전·목표 기준·측정값·관련 회차 ID·원본 위치·통과/실패를 포함한다. 실패한 항목은 원인을 수정한 뒤 관련 항목을 재검증한다. 이 문서는 점검 절차이며 합격 기록이 아니다.
