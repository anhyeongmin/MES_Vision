# 일반·고급 설정 및 설정 이력 · 개선 7번

2026-09-07. 품목·장비 편집 화면을 일반 설정과 고급 설정으로 구분하고, 변경 내용 확인과 저장된 버전의 차이 조회를 추가했다.

## 화면 사용

장비 설정의 기본 화면은 카메라 연결/촬영 조건, 작업 영역, Dobot 포트와 등록 파일 연결을 표시한다. **고급 설정 표시**를 켜면 카메라 설치·좌표계 식별자, 추적 조건, 로봇의 센서·위치 허용 오차·검증된 속도 조건을 표시한다.

품목 설정의 기본 화면은 품목·수량과 추가 분석 조건을 표시한다. 고급 설정에는 모델·정상 기준, 촬영 품질·판정 기준, 집기 기준이 있다. 고급 항목을 숨겨도 입력값은 유지된다. 탭 내용은 스크롤할 수 있다. 자동 노출일 때 수동 노출 입력을 비활성화하고, 자유 수량일 때 고정 수량 입력을 비활성화한다.

**변경 내용 확인**은 현재 입력값을 최초로 불러온 값과 비교해 변경 전후를 표시한다. 미리보기는 저장하지 않는다. 입력값을 다시 바꾸면 이전 미리보기를 숨겨 오래된 내용과 혼동하지 않도록 한다. **변경 내용 접기**로 닫을 수 있다. 저장은 기존 저장 버튼으로 수행하며, 새 확인 팝업이나 자동 검사 시작을 추가하지 않았다.

고급 설정 구분은 화면 정리 기능이다. 사용자 권한이나 비밀번호로 항목 편집을 제한하는 기능은 아니다.

## 버전과 검증 조건

- 카메라 시리얼, 해상도, FPS, 자동/수동 노출 여부 또는 노출값을 변경하면 촬영 조건 번호를 자동 생성한다. 필드는 읽기 전용이며, 변경 미리보기와 저장에서 같은 번호를 사용한다. 같은 편집창에서 설정을 원래대로 돌리면 기존 번호를 유지한다. 작업 영역이나 추적 조건만 바꾸면 촬영 조건 번호를 갱신하지 않는다.
- 기존 좌표 보정이 새 촬영·설치 조건과 맞지 않으면 저장을 차단한다. 보정 파일을 자동 삭제하거나 검증 완료 상태로 만들지 않는다. 설치 위치 변경은 프로그램이 감지할 수 없으므로 고급 설정에서 설치 버전을 새로 입력하고 실제 보정을 확인해야 한다.
- 검증된 촬영 품질값 또는 집기 기준값을 변경하고 기존 기준 버전을 그대로 사용하면 저장을 차단한다. 재검증 후 해당 기준 버전을 새로 입력해야 한다. 연결된 판정 정책·로봇 설정과의 일치 여부는 기존 준비 검사와 운전 조건에서 계속 확인한다.
- 품목의 미등록 선명도/밝기/검사면 높이는 **미등록** 상태로 유지한다. 일반 항목만 편집했다는 이유로 숨겨진 값이 0으로 저장되지 않는다. 실제로 0을 입력한 값과 미등록을 구분한다.

자동 촬영 번호는 변경을 식별하는 값이며, 촬영 품질이나 실제 좌표 정확도를 검증했다는 뜻은 아니다. 품목·장비의 저장 버전 증가와 다른 창의 수정 충돌 차단은 기존 저장소 동작을 유지한다.

## 저장된 설정 이력

앱 안에서 품목 또는 장비 설정을 열면 **저장된 설정 이력**을 사용할 수 있다. 기존 저장소의 기록을 50개씩 조회하고 버전·저장 시각, 선택 버전과 이전 저장 버전의 값 차이를 표시한다. 품목 이력은 해당 품목 ID로 한정한다. 최초 버전은 등록된 값들을 표시한다.

이력 조회는 읽기 전용이다. 이전 버전을 현재 설정으로 복원하거나 적용하지 않으며 모델·카메라·로봇을 시작하지 않는다. 기존 저장 기록에는 변경자·변경 사유가 없으므로 이를 임의로 만들어 표시하지 않는다. 이 기능을 위해 운영 데이터 구조를 변경하지 않았다.
