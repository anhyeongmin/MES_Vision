# ASH 불량 학습 자료 보강 v3

**완료:** 신규 RGB 588장 전부 채택, 기존 학습용 294장과 함께 파생 3,438장 저장. 학습 2,430장, 기본 검증/시험 각126장, 별도 오차 검증/시험 각378장. 전체 RGB·마스크 및 2,844개 불량 좌표 독립 검증, 분할 검사, 초기 가중치 검사와 학습 전 점검이 통과했다. 자료 준비 이후 보강 재학습·새 합성 시험 비교까지 완료했다. 결과는 [재학습 보고서](../artifacts/training/ash-reinforced-v3/README.md)를 참조한다. 최종 안내는 데이터 폴더의 `README.md`다.

1차 합성 학습에서 NG01 구조 누락의 위치 혼동·낮은 확신도와 NG04 벽 변형의 일부 누락이 확인됐다. 다음 학습을 위해 촬영 조건과 물체 잘라내기 변형을 보강한다. 이 작업은 학습 자료 준비이며, 개선 효과는 재학습 후 확인해야 한다.

결과 폴더: `datasets/ash-synthetic-reinforced-v3`. 최종 채택 수량은 `package/preparation.json`, 픽셀·정답 검증 결과는 `package/verification.json`을 기준으로 한다. 기존 CAD, v2 데이터, 1차 모델은 수정하지 않는다.

## 새 촬영 조건과 기존 자료 사용

새 합성 조건은 학습 48개, 검증 18개, 시험 18개로 계획한다. 각 조건에서 정상과 NG 6종을 모두 생성하므로 신규 RGB는 588장이다. 한 조건의 정상·NG는 동일 카메라, 회전, 조명, 재질을 사용한다. 회전은 16방향을 기준으로 작은 변화를 더하고, 밝은 중성색·어두운 중성색·다양한 색상을 나눠 배치한다. 학습 수량을 바꿔도 검증·시험 조건은 달라지지 않도록 분할별 난수 흐름을 분리했다.

기존 v2에서는 학습용 42조건·294장만 재사용한다. 기존 검증·시험 사진은 새 자료에 포함하지 않는다. 이미 결과를 확인한 v2 시험은 개발 근거로 남긴다. 자료 준비 시점에는 새 시험 추론을 하지 않았으며, 이후 승인된 재학습의 검증 선택을 마친 뒤 새 시험을 평가했다. 모든 자료가 같은 CAD 7종을 재사용하므로 새 시험도 알려진 형상의 새로운 합성 촬영 조건 평가다. 새로운 실물이나 불량 형상에 대한 독립 평가가 아니다.

## 물체 잘라내기

- 학습 기본 자료: 전체 7종에 원래 물체 영역과 변형 2개, 총 3개씩.
- 보강 대상: 정상·NG01·NG04에는 추가 변형 2개를 더해 5개씩. 추가 변형도 세 종류가 같은 잘라내기 조건을 공유한다.
- 기본 검증·시험: 신규 사진마다 원래 물체 영역 1개씩.
- 오차 시험: 같은 검증·시험 사진의 이동·확대 변형 3개를 `crop-stress`에 별도 저장한다. 기본 평가와 합쳐 독립 표본 수를 늘렸다고 주장하지 않는다.

잘라내기 이동은 물체 상자의 한 변 대비 최대 ±10%, 배율 후보는 0.94~1.30이다. 모든 후보는 7종의 물체 상자 면적을 각각 95% 이상 보존하고, 여섯 불량 위치에 4픽셀 이상 여유가 남아야 한다. 정상 사진에도 모든 불량 위치의 검사 기준을 함께 적용해 정상과 불량의 자르기 규칙이 달라지는 단서를 막는다. 실제로 채택된 오차와 배율은 `crop-ledger.json`에 기록한다. 선택 기준 때문에 실제 범위는 후보 범위보다 좁을 수 있다.

불량 마스크가 일부라도 잘리거나 정답 상자가 벗어나면 저장하지 않는다. 정상은 빈 마스크와 불량 주석 0개를 유지한다. 보강을 위해 물체를 지우거나 새로운 가짜 불량을 사진에 합성하지 않는다.

모든 계획 조건이 통과하는 경우 학습용은 2,430장(정상·NG01·NG04 각각 450장, 다른 NG 각각 270장), 기본 검증·시험은 각각 126장, 별도 오차 시험은 각각 378장이다. 이는 잘라내기 파생 이미지 수이며 촬영 표본 수와 다르다. 보강 클래스의 빈도가 늘어나므로 다음 학습에서 종류별 정밀도와 재현율을 따로 확인해야 한다.

## 품질·정답 검사

기존 기하·가림·최소 영역·정상 대비 RGB 차이 기준을 그대로 사용한다. 새 조건에서 NG 한 종류라도 실패하면 해당 정상·NG 7종을 함께 제외한다. 조건별 제외 사유를 보고서에 보존한다. 약한 차이가 자동 기준을 통과했다고 모델이 구별할 수 있다는 뜻은 아니다.

내보내기 이후 원본 RGB를 직접 잘라 비교하고, 마스크 픽셀 보존, 마스크에서 계산한 정답 상자, 클래스·면적, 형제 이미지·촬영 조건·픽셀의 분할 간 중복을 다시 검사한다. 생성 표시가 들어간 그림은 `review`에만 저장한다. `package/defect-crops`의 학습 입력에는 표시가 없다.

STL 단위는 원본 좌표를 mm로 해석한 가정이며 실제 카메라 초점·왜곡·인쇄 표면을 실측해 맞춘 데이터가 아니다. 가상 카메라 높이를 실제 로봇 설정에 사용하지 않는다.

## 실행

```powershell
& ./.venv/Scripts/python.exe scripts/build_ash_reinforcement.py prepare --root datasets/ash-synthetic-reinforced-v3
& ./.venv/Scripts/python.exe scripts/build_ash_reinforcement.py render --root datasets/ash-synthetic-reinforced-v3
& ./.venv/Scripts/python.exe scripts/build_ash_reinforcement.py export --root datasets/ash-synthetic-reinforced-v3
& ./.venv/Scripts/python.exe scripts/verify_ash_reinforcement.py --root datasets/ash-synthetic-reinforced-v3
```

준비 명령은 새 폴더에만 실행한다. 렌더는 계획·코드·이미지 해시가 일치하는 완료 장면을 재사용한다. 내보내기는 `package.pending`에서 검증한 후 `package`로 전환한다. 완료한 패키지를 덮어쓰지 않는다. 생성 중에는 `quality_ash_reinforcement.py`로 완료된 영수증을 기다리며 품질 검사와 최종 내보내기를 이어갈 수도 있다.
