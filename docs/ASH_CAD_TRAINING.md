## 최신: U20CAM용 소량 합성 촬영 샘플 생성

2026-09-11. 사용자가 카메라를 **INNOMAKER U20CAM-720P**로 변경했다. Blender 4.5.7 LTS/Cycles/RTX3090으로 1280×720 RGB 상세21장(7종×3조건)·전체3장(각7물체)을 생성했다. 불량영역18개, 상세물체21개, 전체물체21개를 COCO로 저장했다. 정상상세3장에는 불량주석이 없다. 결과 폴더는 `datasets/ash-synthetic-samples-v1`, 안내는 그 폴더의 `README.md`다.

공식 수평화각102°를 이상적 핀홀의 출발점으로 사용했다. 실제 렌즈왜곡·근접초점·인쇄재질·노이즈·MJPEG압축은 맞추지 않았다. 가상촬영높이는 원본mm가정의 시각적 구도이며 실제 카메라 최소초점거리나 로봇 운전높이로 검증되지 않았다. 제조사 사양은 [U20CAM-720P](https://www.inno-maker.com/product/u20cam-720p/)를 참고한다.

불량정답은 정상/NG의 동일 카메라·물체자세에서 보이는 깊이 차이를 계산해 2px 여유의 상자로 만든다. 깊이허용차는 장면단위1e-6m다. 반투명표시와상자는 `review/`에만 있으며 `rgb/`는표시없는원본이다. 주석은 기하학적인 불량부위를 뜻하며 그림자 전체나 RGB차이 전체를 라벨로 붙이지 않는다. 원근깊이·가림·누락영역 등 단위시험6개와 데이터무결성/주석/정상음성/짝장면검증이 통과했다. 자동검증 `verification.json`.

이 자료는 학습/평가분할 전 **소량 검토 샘플**이다. 기존 학습 실행기에 바로 연결하는 대규모분할데이터는 아직 아니다. 동일CAD7종을재사용하므로독립실물평가로주장하지않는다. 모델학습/가중치교체는하지않았다. 실제프로그램의카메라연결코드는아직D405전용이므로UVC연결전환은별도작업으로남아있다.

아래 내용은 앞선 원본 확인 단계의 기록이다.

2026-09-11. 사용자가 지정한 `C:/Users/alexi/Downloads/OKNG`에서 정상 1종·NG 6종을 확인했다. 각각 IPT와 binary STL이 있다. 형상은 STL로 확인했고 IPT의 모델 내부는 해석하지 않았다. 별도 원본 보관은 `datasets/cad-sources/ash-v1/cad-sources.json`에 파일 경로와 SHA256을 기록했다. 다운로드 폴더의 원본을 수정하지 않았다.

| 코드 | 파일 | 비교한 형상 |
|---|---|---|
| OK | ASH_OK | 홈 내부 원형 보스 2개 |
| NG01 | ASH_NG01_MissingBoss | 한쪽 보스 누락 |
| NG02 | ASH_NG02_ExtraMaterial | 내부 사각 돌출 추가 |
| NG03 | ASH_NG03_Crack | 내부 바닥 균열 형태의 홈 |
| NG04 | ASH_NG04_WallDeformation | 한쪽 내벽 형상 변화 |
| NG05 | ASH_NG05_HoleDefect | 한쪽 보스 구멍 막힘 |
| NG06 | ASH_NG06_SurfaceDefect | 내부 원형 표면 함몰 |

모든 STL의 경계는 X=-8..8, Y=0..14, Z=-10..10이다. 사용자는 ‘STL 그대로 출력’이라고 했다. 원본 크기를 변경하지 않는다. STL의 물리 단위는 확인되지 않았으므로 실제 크기 16×14×20mm는 슬라이서가 mm 단위·100% 배율로 읽는 경우에만 해당한다. 이 가정을 로봇 좌표 보정이나 실제 설치값으로 등록하지 않았다.

여섯 축 방향의 직교 투영을 비교하면 +Y에서 바라볼 때만 정상 대비 NG 6종의 표면 깊이 변화가 보인다. 홈과 보스가 보이는 이 면을 검사면 후보로 정했다. 나머지 다섯 방향의 단순 직교 깊이 비교에서 차이 픽셀은 0이었다. 실물의 조명·카메라 해상도·원근에서 실제로 구별되는지는 별도 확인해야 한다.

7개 파일 모두 파싱에 성공했다. 좌표를 소수점 5자리로 합쳐 검사했을 때 두 삼각형에 공유되지 않는 변은 0개, 면적이 거의 0인 삼각형은 0개였다. 자기 교차·프린팅 가능성 전체를 검증한 것은 아니다. 형상과 메시를 자동 수정하지 않았다.

`artifacts/cad-ash/inspection-20260911-v2/inspection-face.png`는 형상을 확인하는 진단 그림이다. 위는 깊이에 따른 인공 명암, 아래 빨간색은 정상 대비 보이는 깊이 차이다. **실제 RGB 촬영을 재현한 학습 이미지가 아니며 빨간색을 모델 입력으로 사용하지 않는다.** 위치 정답 후보로 쓸 때도 정상의 누락 영역·가림·회전·경계 차이 등을 확인해야 한다.

## 다음 합성 데이터 단계

1. 원본 단위와 +Y 검사면을 기준으로 렌더 장면을 구성하고 조명·재질·배경·배치·회전을 변화시킨다. 카메라 실제 배율 자료가 없으면 여러 배율을 다루되 실물 측정값으로 표기하지 않는다.
2. 전체 촬영용 물체 검출은 정상/NG 모두 `ASH` 물체로 주석한다. 별도 근접용 물체 검출 자료도 같은 물체 클래스가 필요하다.
3. 상세 불량 검출은 NG01~NG06의 불량 부위를 주석하고, 정상 상세 이미지의 불량 주석은 비워 둔다. 전체 물체 상자를 불량 위치로 대신하지 않는다.
4. 소량 샘플에서 각 불량이 렌더 RGB에 실제로 보이는지와 정답 영역을 검토한 후 대량 생성한다. 특히 균열·표면 함몰은 조명에 따라 안 보일 수 있다.
5. 기존 RF-DETR 학습 경로에 합성 자료로 명시해 연결한다. 같은 CAD 7종을 재사용한 합성 평가가 새로운 불량 형상이나 실물에 대한 독립 평가라는 주장을 하지 않는다. 최종 실물 평가는 별도 확보한다.

현재 완료 범위는 **형상 진단·검사면 후보·정상/NG 매핑·원본 보관**이다. 사진형 합성 데이터 생성, COCO 정답 확정, 학습 및 가중치 교체는 아직 수행하지 않았다.
